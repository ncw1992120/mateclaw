# 平安企业认证（领航）集成手册

> 适用范围：`mateclaw-dataagent`（DataAgent 服务）+ `mateclaw-dataagent-ui`（DataAgent 前端）。
> 模式：**私有协议类 CAS SSO，登录页账密代验（credential proxy）**——用户口令在登录页输入，由 DataAgent 转发给领航服务校验，无浏览器重定向跳转；SSO 免登走共享域 Cookie 静默换取会话。

---

## 1. 整体架构与调用链

```
┌──────────────┐  /v1/auth/login        ┌─────────────────────┐
│ DataAgent-UI │ ─────────────────────► │      DataAgent      │
│ LoginView    │  /v1/auth/captcha      │  (port 18089)       │
│ 三标签页表单  │ ◄───────────────────── │  DataAgentAuthService│
│ 静默SSO免登   │                        │   ├ 路由与限速        │
└──────────────┘                        │   ├ 影子账号(本地表)   │
                                        │   └ JWT 签发(复用)    │
                                        └─────────┬───────────┘
                                                  │ RestTemplate (HTTPS)
                                                  ▼
                                        ┌─────────────────────┐
                                        │  领航认证服务（平安侧） │
                                        │ /v3/assertion        │
                                        │ /v3/assertion/captcha│
                                        │ /v3/assertion/sso    │
                                        │ /v3/sso/renewal      │
                                        └─────────────────────┘
```

关键设计点：

- **账密代验**：口令只在内存中由 DataAgent 转发给领航，任何日志不得输出请求体/口令/Cookie（代码中已约束）。
- **影子账号**：领航校验通过后，在本地 `mate_user` 表自动创建/复用影子账号（随机口令、不可本地登录），并通过 `dataagent_enterprise_account` 表记录映射（来源 `PILOT`）。JWT 由本地 `AuthService` 签发，下游过滤器/拦截器零感知。
- **双轨路由**：企业认证开启后，普通账号走领航；`local-fallback-users` 白名单（默认 `admin`）仍走本地密码校验，防止企业侧故障锁死管理员；前端「本地账号登录」表单仅对白名单账号开放。

## 2. 集成前置条件（需平安侧/基础设施配合）

1. **服务端点**：确认 4 个端点的生产地址与端口：
   - 登录断言：`POST /v3/assertion`
   - 图形验证码：`POST /v3/assertion/captcha`
   - SSO 校验：`POST /v3/assertion/sso`
   - SSO 续期：`POST /v3/sso/renewal`
2. **网络可达**：DataAgent 出网（HTTPS）到领航服务；生产环境走专线/内网域名，超时建议 5s。
3. **TLS（生产必做）**：
   - 领航证书 SAN 必须匹配实际访问域名（联调阶段曾出现 dev 证书主机名不匹配）；
   - 将平安 CA（根/中间证书）导入 JVM 信任库（`cacerts` 或独立 truststore）；
   - 当前代码为联调便利保留了「信任所有证书 + 绕过主机名校验」的实现（`PilotIdentityProvider` 内 `TRUST_ALL_SSL_CONTEXT`），**上线前必须替换为受信方案并校验域名**，否则 TLS 被中间人劫持会直接泄露转发的明文口令。
4. **SSO Cookie（仅免登需要）**：确认浏览器共享域 Cookie 名（默认 `CAS_SSO_COOKIE`）、Domain `.paic.com.cn`、非 HttpOnly（前端 JS 可读）。DataAgent 必须部署在 `*.paic.com.cn` 域名下才能读到该 Cookie。
5. **账号体系**：确认用户开通了 UM（域账号）或 AD（用户主机账号）之一；两者为当前支持的认证类型。

## 3. 配置说明

配置块 `mateclaw.pilot.*`（`src/main/resources/application.yml`），全部支持环境变量覆盖：

| 配置项 | 环境变量 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `MATECLAW_PILOT_ENABLED` | `true` | 总开关；`false` 时完全退回本地账密登录 |
| `auth-server` | `MATECLAW_PILOT_AUTH_SERVER` | dev 地址 | 登录断言端点 |
| `captcha-server` | `MATECLAW_PILOT_CAPTCHA_SERVER` | dev 地址 | 验证码端点 |
| `sso-server` | `MATECLAW_PILOT_TOKEN_SERVER` | dev 地址 | SSO 校验端点 |
| `sso-renewal-server` | `MATECLAW_PILOT_SSO_RENEWAL_SERVER` | dev 地址 | SSO 续期端点 |
| `authn-type` | `MATECLAW_PILOT_AUTHN_TYPE` | `UM` | 默认认证类型（UM=域账号/AD=主机账号），请求可逐次覆盖 |
| `life-time` | — | `432000` | 领航侧断言生命周期（秒），与本系统 JWT 无关 |
| `timeout` | — | `5s` | 连接/读取超时 |
| `local-fallback-users` | — | `[admin]` | 企业模式下仍走本地校验的兜底白名单 |
| `sso-cookie-name` | `MATECLAW_PILOT_SSO_COOKIE_NAME` | `CAS_SSO_COOKIE` | 前端免登探测读取的 Cookie 名；置空关闭免登 |

最小配置示例（生产）：

```yaml
mateclaw:
  pilot:
    enabled: ${MATECLAW_PILOT_ENABLED:true}
    auth-server: https://authnadminservice.prod.paic.com.cn:10081/v3/assertion
    captcha-server: https://authnadminservice.prod.paic.com.cn:10081/v3/assertion/captcha
    sso-server: https://authnadminservice.prod.paic.com.cn:10081/v3/assertion/sso
    sso-renewal-server: https://authnadminservice.prod.paic.com.cn:10081/v3/sso/renewal
    sso-cookie-name: CAS_SSO_COOKIE
    authn-type: UM
    local-fallback-users:
      - admin
```

## 4. 认证流程

### 4.1 账密代验（主链路）

1. 前端登录页提交 `POST /v1/auth/login`，请求体含 `username`、`password`、`authnType`（UM/AD）、可选 `requestId`+`validCode`（验证码）、可选 `channel=local`。
2. DataAgent 路由：`channel=local` 且不在白名单 → 直接 403 提示「请使用开机账号/UM 账号登录」；否则企业链路（或白名单本地链路）。
3. 企业链路：`PilotIdentityProvider` 转发领航断言 → 成功则 `ShadowAccountService` 建/取影子账号 → 本地 `AuthService` 签发 JWT → 返回与本地登录一致的响应（含工作区列表）。
4. 登录写审计日志：`[Auth] login success user=[..] channel=[LOCAL|PILOT_UM|PILOT_AD|PILOT_SSO]`。

### 4.2 验证码分支

领航风控返回 `NEED_RAND_CODE` → DataAgent 翻译为 **HTTP 429** → 前端调 `GET /v1/auth/captcha?authnType=UM|AD` 拉取验证码图 → 携带 `requestId`+`validCode` 重试登录；验证码错误（`WRONG_IMAGE_CODE`）→ **HTTP 401**，前端提示并刷新验证码。前端「本地账号登录」表单不触发验证码。

### 4.3 SSO 静默免登

1. 前端挂载后调 `GET /v1/auth/mode`，返回 `provider=pilot`、`authTypes=[UM,AD]`、`ssoCookieName`。
2. 若配置了 Cookie 名且浏览器持有 `CAS_SSO_COOKIE`（仅 `*.paic.com.cn` 域下可读），静默调 `POST /v1/auth/sso/login`。
3. DataAgent 转发领航 SSO 校验，成功后同样走影子账号 + JWT 签发。免登失败静默降级，不打断用户手动登录。
4. 会话期间可调 `POST /v1/auth/sso/renewal`（需认证）续期企业侧会话，失败仅告警、不影响本地 JWT。

### 4.4 失败与限速

- 凭据类失败（HTTP 401）按用户名计数，**10 次/5 分钟** 窗口后返回 403「登录失败次数过多」；登录成功立即清零。
- 验证码流程（429）与基础设施故障（502）不计数。
- 凭据错误统一文案「用户名或密码错误」，不向前端泄露领航侧 `message`，防账号探测。

## 5. 对外接口一览

| 接口 | 认证 | 说明 |
|---|---|---|
| `POST /v1/auth/login` | 公开 | 账密登录（本地/企业双轨，`authnType`、`channel`、`requestId`/`validCode`） |
| `GET /v1/auth/captcha?authnType=` | 公开 | 拉取图形验证码（base64 + requestId） |
| `GET /v1/auth/mode` | 公开 | 认证模式探测（`provider`/`authTypes`/`ssoCookieName`） |
| `POST /v1/auth/sso/login` | 公开 | SSO Cookie 免登 |
| `POST /v1/auth/sso/renewal` | 需登录 | SSO 会话续期 |
| `GET /v1/auth/me` | 需登录 | 当前用户信息 |
| `PUT /v1/auth/password` | 需登录 | 修改本地密码 |

公开端点白名单位于 `DataAgentSecurityConfig`（`/v1/auth/login|captcha|mode|sso/login`），其余走 JWT。

### 主要错误码

| HTTP | 含义 | 前端处理 |
|---|---|---|
| 401 | 用户名或密码错误 / 图形验证码错误 | 提示并刷新验证码（登录页不触发登出跳转） |
| 403 | 账号未开通本地登录（请用开机/UM 账号）或限速封锁 | 按 `message` 提示 |
| 429 | 需要图形验证码 | 拉取验证码后重试 |
| 502 | 企业认证服务暂不可用/未配置 | 提示稍后重试或联系管理员 |

## 6. 领航协议契约（对接要点，联调对照）

### 6.1 登录断言 `POST /v3/assertion`

请求体：

```json
{
  "username": "zhang.san",
  "password": "******",
  "authnType": "UM",
  "lifeTime": "432000",
  "additionalInfo": {
    "requestId": null,
    "validCode": null
  }
}
```

- `authnType` 取值 `UM`（域账号）/ `AD`（用户主机账号）；`lifeTime` 为必传参数（秒）。
- 响应判定：`code == 0` 且 `message` 非 `NEED_RAND_CODE` 即成功；`code` 兼容数字 `0` 与字符串 `"0"`。
- **注意：断言接口不返回 PRINCIPAL_NAME**——认证通过即以登录表单输入的账号为身份（代码会防御性回退读取 `content.userName`/`content.PRINCIPAL_NAME`，但联调时不要依赖）。

### 6.2 验证码 `POST /v3/assertion/captcha`

请求体（`authnMechanism` 与认证类型同值）：

```json
{
  "authnMechanism": "UM"
}
```

响应：`requestId` + `captchaImage`（base64），字段可能位于根级或 `content` 内，代码已做双层兼容提取。

### 6.3 SSO 校验 `POST /v3/assertion/sso`

请求体：

```json
{
  "authnType": "UM",
  "lifeTime": "432000",
  "ssoCookie": "…",
  "ssoType": "CAS_SSO_COOKIE"
}
```

响应：`code == 0` 且 `isSuccess == true` 且返回用户标识（`userName`，防御性回退 `content.userName`/`content.PRINCIPAL_NAME`）即成功。**用户标识仅此接口返回**。

### 6.4 SSO 续期 `POST /v3/sso/renewal`

请求体：

```json
{
  "authnType": "UM",
  "ssoType": "CAS_SSO_COOKIE",
  "ssoCookie": "…"
}
```

失败仅告警。

> 联调须知：报文字段名以领航线上契约为准（当前代码按 `authnType`/`authnMechanism` 发送，如接口实测要求 `authType` 需同步调整 `PilotIdentityProvider` 内 3 处字段名）。

## 7. 前端集成要点（DataAgent-UI）

- 登录页顶部三个标签页：**开机账号登录**（开机账号/开机密码）、**UM 账号登录**（UM/UM 密码）、**本地账号登录**（本地账号/本地密码）。前两者 `authnType` 分别为 `AD`/`UM`，本地项带 `channel=local`。
- 页面挂载先查 `/v1/auth/mode`：`provider=pilot` 时展示 UM/AD 选择；配置了 `ssoCookieName` 且浏览器可读到该 Cookie 时静默调 `ssoLogin`。
- 429 分支拉取验证码并展示（base64 图片），携带 `requestId`+`validCode` 重试；401「图形验证码错误」刷新验证码。
- axios 拦截器对包含 `/auth/sso/login` 的请求静默处理失败，避免免登失败被当作用户登出。

## 8. 上线检查清单

- [ ] 4 个端点地址/端口替换为生产值（环境变量注入，不落代码）
- [ ] 平安 CA 导入 JVM 信任库；验证 HTTPS 证书 SAN 匹配访问域名
- [ ] 移除/禁用「信任所有证书、绕过主机名」逻辑（或确认其仅存在于联调分支）
- [ ] `enabled` 按环境显式配置（生产只对试点域名开启）
- [ ] `local-fallback-users` 仅保留最小兜底集合（默认 `admin`），并确保其本地密码强度
- [ ] `dataagent_enterprise_account` 表已由 Flyway 迁移创建（`V217`）
- [ ] 端到端验证：UM/AD 账密登录、验证码 429→重试、`GET /v1/auth/mode`、SSO 免登（需 `*.paic.com.cn` 域名）、续期
- [ ] 日志抽查：无口令/Cookie 泄漏；登录成功含 `channel` 审计字段；403 引导文案正确
- [ ] 确认企业侧会话超时与本地 JWT 过期策略（续期接口是否纳入联调范围）

## 9. 常见问题（FAQ）

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 登录返回 502「企业认证服务暂不可用」 | 端点不通 / TLS 证书不信任 / 主机名不匹配 / 超时 | 确认网络与证书；联调期临时用全信任配置验证，生产必须修证书 |
| 登录提示需要验证码（429）且反复出现 | 领航风控；验证码字段位置与契约不一致 | 对照 6.2 契约核对 `requestId`/`captchaImage` 字段层级（根级 vs `content`） |
| 本地账号登录返回 403「未开通本地登录」 | 该账号不在 `local-fallback-users` 白名单 | 用开机账号/UM 账号登录，或按需加白名单 |
| 免登未触发 | Cookie 名/域不匹配；HttpOnly；DataAgent 不在 `*.paic.com.cn` 域 | 前端 F12 确认 Cookie 存在且 JS 可读 |
| 连续输错密码后被封锁 403 | 限速策略（10 次/5 分钟） | 等待窗口过期；成功登录即清零 |
| 领航返回成功但登录仍 401 | 断言后身份解析为空（PRINCIPAL_NAME 场景） | 确认走的是账密代验（身份=表单账号），非 SSO 接口 |
