# 异常检测方法论

本文说明 `scripts/anomaly_detect.py` 的实现口径：算法公式、参数默认值、方法选择决策树、门限设定与严重度标准。所有方法均为业界标准做法，实现只依赖 Python 标准库。

> **本文是脚本行为的人工镜像**：阈值与参数以 `scripts/anomaly_detect.py` 的常量为准，脚本运行时不读取本文。改动实现口径时，请同步更新本文的参数速查（第七节）、SKILL.md 的方法速查表，以及脚本模块头部的载荷说明，然后运行 `scripts/check_doc_consistency.py`（或仓库根目录 `make check-skill-docs`）校验——该脚本逐项比对文档与代码常量，漂移时以非零码退出。

## 一、总体流程：先分解，后检测

时间序列异常检测的标准做法（STL 残差、S-H-ESD 一脉）是**先把可解释的结构剥离，再对残差做点检测**。直接对原序列做点检测会把周期波动（周末高峰、月末冲量）判成异常。

```
输入时间序列（按时间升序）
   │
   ├─ 1. 结构识别 ─ 自相关法推断季节周期；Theil–Sen 局部线性趋势 + 相位中位数季节 → 稳健基线
   │        └─ 三重门限判定"是否存在真实季节结构"
   │
   ├─ 2. 残差检测 ─ 存在季节结构：对(实际值 − 基线)残差检测；否则：直接对原序列检测
   │
   ├─ 3. 位移确认 ─ 变点检测（前后双窗中位数比较）：显著的水平位移定位起点，绕过投票阈值
   │
   ├─ 4. 集成投票 ─ 多检测器命中的点数达到多数票阈值才判为异常；高相关方法凑票需得分 ≥ 4.5
   │
   ├─ 5. 分级分类 ─ 偏离幅度 + 稳健得分 → 严重度；方向 → 尖峰/凹陷；连续同向点 → 水平位移
   │
   └─ 6. 实际意义过滤 ─ 相对偏离低于 minDeviationRatio 的点不报告，仅计入 warnings
```

## 二、基础统计量

| 统计量 | 公式 | 说明 |
|-------|------|------|
| 中位数 median | 排序后中间值 | 抗离群点的位置估计 |
| 稳健尺度 σ̂（MAD） | `1.4826 × median(\|x − median(x)\|)` | 1.4826 是正态下 MAD→σ 的一致性系数 |
| 稳健尺度 σ̂（IQR） | `(Q3 − Q1) / 1.349` | 1.349 是正态下 IQR→σ 的一致性系数 |
| 稳健尺度 σ̂（平均绝对偏差） | `1.253314 × mean(\|x − median(x)\|)` | 正态下平均绝对偏差→σ 的一致性系数 |
| 缩尾标准差（Huber 型） | 取值缩尾到 ±4×MADσ 后的样本标准差，与 MADσ 取较大者 | 校正分解残差"内挤+重尾"导致的 MAD 低估 |
| 分位数 | 线性插值 | 与 `numpy.percentile(..., method="linear")` 一致 |

**尺度估计的退化链**：稳健尺度按 `MAD → IQR/1.349 → 平均绝对偏差×1.2533 → 样本标准差` 逐级退化。取值高度重复的序列（整数化、四舍五入后的指标）会有超过半数取值与中位数完全相同，此时 MAD 恰为 0；若直接跳到样本标准差，尺度会被少数极端点抬高几个量级，真正的异常反而检不出来。中间两级同样不被极端值主导。

**MAD 分支的缩尾校正（与 MADσ 取大）**：分解残差存在"内挤 + 重尾"结构——季节项用同一样本的相位中位数拟合，带过拟合效应，实测残差 MAD=1.85 而标准差=5.79，MAD 低估真实噪声近一半，得分被系统性放大。把残差缩尾到 ±`WINSOR_BOUND_SIGMA`(4.0)×MADσ 后取样本标准差（Huber 稳健尺度的等价形式）：缩尾界由 MADσ 决定，故不被极端值抬升，又能反映内挤之外的真实散布；最终尺度取 `max(MADσ, 缩尾标准差)`。

**差分序列用纯 MAD（不含缩尾）**：位移确认的变点检测在差分序列上反推 σ：`σ_diff = MAD尺度(一阶差分) × 1.253314 × √(2/7)`（一阶差分方差为 2σ²，单侧 7 点窗中位数差异的标准误按平均绝对偏差换算）。差分中阶跃只贡献 1~2 个离群点，正是需要 MAD 免疫的对象；若混入缩尾/标准差校正，阶跃差分的方差会撑大尺度、稀释位移 Z（实测被抬高 21%），故差分场景退回纯 MAD 尺度。

## 三、单方法检测器

所有检测器输入同一列"被检序列"（原序列或残差序列），输出 `{索引: {得分, 期望值}}`。得分带符号：正为向上偏离，负为向下偏离。

### 1. MAD 稳健修正 Z 分数（`mad`，默认首选）

```
Z_i = (x_i − median(x)) / (1.4826 × MAD)        |Z_i| > 3.5 判为异常
```

阈值 3.5 出自 Iglewicz & Hoaglin《Volume 16: How to Detect and Handle Outliers》的修正 Z 分数（对应的等价写法为 `0.6745 × (x − median) / MAD`）。相比 3σ，MAD 不受离群点污染，**通用首选**。

### 2. 经典 Z 分数（`zscore`）

```
Z_i = (x_i − μ) / σ                            |Z_i| > 3.0 判为异常
```

μ/σ 为均值与样本标准差。检出率高但对离群点敏感（异常点自身会抬高 σ），仅在序列干净、近似正态时使用。

### 3. Tukey 箱线图围栏（`iqr`）

```
下围栏 = Q1 − k × IQR      上围栏 = Q3 + k × IQR
k = 1.5 判为离群（outlier），k = 3.0 判为极值（extreme，直接定 CRITICAL）
```

出自 Tukey《Exploratory Data Analysis》。基于分位数，对偏斜分布与小样本友好；命中 `extreme` 围栏的点直接判为 CRITICAL。

### 4. 局部线性趋势残差（`moving`）

```
期望值 ê_i = 邻域（±window/2，剔除当前点）Theil–Sen 稳健线性拟合在 i 处的取值
残差 r_i = x_i − ê_i        |r_i / σ̂(r)| > 3.5 判为异常
```

**为什么用局部线性回归而不是移动平均/中位数**：

- 移动平均：窗口内的尖峰会抬高邻域期望，异常点"污染"其邻居 → 连带误报
- 移动中位数：序列末端会滞后于趋势，趋势序列的末点产生伪残差 → 末端误报
- Theil–Sen 线性拟合：斜率为所有点对斜率的中位数，单个离群点带不偏斜率，且可外推到窗口之外，趋势与边界都不产生伪残差

Theil–Sen 见 Theil (1950)、Sen (1968)；"用邻域稳健估计做期望"属于 Hampel 滤波思想。

### 5. 时序分解残差（`stl`）

`stl` 不是独立算法，而是**显式要求走"分解 + 残差检测"路径**：结构与 `auto` 相同（自相关推断周期 → 趋势 + 季节基线 → 残差检测），区别在于它不是"可选方法"而是路径声明。未检出显著季节结构时，退化为一元稳健 Z 分数（MAD）并给出提示。

趋势项用 Theil–Sen 局部线性拟合（半窗 = `TREND_WINDOW_PERIODS` 个周期）；季节项用**相位中位数**（同类季节位置取中位数，避免异常点外溢到同相位点）。

### 6. EWMA 指数加权控制图（`ewma`）

```
z_i = α x_i + (1 − α) z_{i−1}          （z_0 = x_0）
σ_z = σ̂ × √(α / (2 − α))              |z_i − 目标| / σ_z > L 判为异常
α = 0.3，L = 3.0
```

出自 Roberts (1959) 与 SPC 标准做法，能捕捉缓慢漂移。**不参与 `auto` 集成**：EWMA 会把单个尖峰平滑后持续外溢，使尖峰之后多个正常点被连带判为"水平位移"；需要检测持续漂移时显式指定。

### 7. 水平位移确认（`shift`，变点检测；不单独选用）

多方法集成（`auto`）时自动启用的**确认通道**，思想同 PELT/CUSUM 一类变点检测的双窗比较。点检测器对水平位移天然不敏感——位移幅度被分摊到每个点上，单点偏离可能低于门限——故用专门的变点统计量补位：

```
对每个候选位置 t：Z_t = (median(前 7 点) − median(后 7 点)) / σ_diff
σ_diff = MAD尺度(一阶差分) × 1.253314 × √(1/m_前 + 1/m_后) / √2
（一阶差分方差为 2σ²，MAD 反推后除 √2 得 σ；满窗 m=7 时退化为 ×1.253314×√(2/7)）
```

- 扫描前先做 Theil–Sen 全局去趋势，避免线性趋势被误判为位移
- σ_diff 用差分的**纯 MAD** 尺度：阶跃只贡献 1~2 个离群差分点，被中位数免疫，尺度不被位移自身污染；差分仅取网格相邻点对，缺口两侧不差分（跨缺口的多日变化会抬高 σ、稀释位移 Z）
- **窗口按时间网格取**：候选与窗口都以网格坐标（真实时间）计，缺行槽位跳号；边缘截断的窗口（界内槽位不足 7 个）不判定；完整窗口内允许至多 `SHIFT_WINDOW_MISSING_TOLERANCE`(3) 个缺失槽位（每窗至少 4 点），此时标准误按实际点数放大（m_前/m_后 为各窗实际点数）。按下标取窗会让缺口后的窗口整体前移、跨缺口的窗口跨度被压缩；忽略缺失点则等于假装满窗精度（实测容忍度 2→3 在"起点前连缺 3 天"场景召回 46%→59%，干净序列位移误报不变；代价是边界难度位移（满窗 Z≈3.9）在窗口缺 2~3 点时可能被 SE 放大压到门限之下）
- |Z| ≥ `SHIFT_Z_THRESHOLD`(3.5) 的候选按 |Z| 降序贪心聚簇（半径 7），每簇取最强者；起点取"离后窗水平更近"的首点，并向前扩展（沿占用点步进，None 行不中断）
- 确认成立的位移：起点判为 `LEVEL_SHIFT`、期望值取位移前水平，**绕过投票阈值**，严重度不低于 `MAJOR`

**误报的统计本性**：白噪声下该扫描的 max|Z| p95≈3.2、p99≈3.9（重叠窗口的中位数统计量去相关快），因此 3.5 门限下每条干净序列的位移扫描误报率天然约 5%，属统计本性而非缺陷；归一化已验证正确（单窗 Z 标准差 ≈ 1.0）。要求更低误报可把 `SHIFT_Z_THRESHOLD` 提到 4.0，代价是弱位移召回下降（−3σ×6 点约从 62% 降到 45%）。

**能力边界**：−3σ 幅度、持续 6 点的位移是边界难度（基准召回约 62%，−4σ 约 92%）；位移幅度相对噪声越小、持续越短，越容易漏检。需要更高灵敏度时显式指定 `ewma`（对缓慢漂移更敏感），或走 `python_analysis` 用 numpy 自实现 CUSUM（`statsmodels.stats.diagnostic.breaks_cusumolsresid` 也可用；PELT 需额外安装 `ruptures`，镜像未预装）。

## 四、结构识别与三重门限

### 周期推断（自相关法）

1. 先把时间映射到均匀网格坐标：`grid_i = round((t_i − t_0) / 步长)`（步长优先取占严格多数的间隔——日/周粒度日历对齐数据的真实采样节奏，任意缺口密度下不被多日缺口抬高；无多数时取间隔中位数，坐标塌缩时再退到最细采样间隔重试），缺行处坐标跳号；按下标取相位会让缺口之后的季节相位整体前移（周末高峰对齐到工作日、基线失真），网格坐标保证相位始终与真实时间对齐。时间不可解析、重复或缺口过密到无法构建网格时退回位置下标并在 `warnings` 中提示
2. 差分只在网格相邻点对上计算（缺口两侧不差分，避免多日变化混入差分方差），再用 ±3×MAD 稳健缩尾：单个极端异常点会把差分的方差抬高几个量级，不缩尾会让真实季节峰淹没在异常点的伪相关里
3. 计算滞后 2..12 的自相关系数，按网格距离配对（缺口不错位）：`ACF(k) = Σ(x_i − x̄)(x_{i+k} − x̄) / Σ(x_i − x̄)²`
4. 显著性门限 `threshold = max(0.3, 2/√n)`：白噪声自相关的波动幅度约为 1/√n（Bartlett 近似），固定门限在短序列上会把噪声峰误判为周期
5. 取达到峰值 90% 的**最小**滞后，避免选中峰值的谐波（如 7 的倍数）

### 三重门限（分解是否可信）

| 门限 | 判据 | 目的 |
|------|------|------|
| 季节强度 Fs | `Fs = max(0, 1 − Var(残差)/Var(去趋势)) ≥ 0.3` | 季节项是否解释了主要波动（STL 季节强度的标准定义） |
| 季节性效应量 | 季节峰谷差 ≥ `SEASONAL_AMPLITUDE_SNR`(3.0) × 残差标准差 | 防止相位中位数只是"过拟合随机噪声" |
| 拟合不过度完美 | `median(\|残差\|) ≥ 0.03 × σ̂(原序列)` | 残差几乎为 0 说明序列是确定性周期重复，分解会把噪声压到近 0，微小偏离被放大成天文级得分；此时退回原序列检测 |

计算强度与效应量前，先**按残差绝对值截尾**（`STRENGTH_TRIM_RATIO = 5%`）再算两组方差：否则单个极端异常点会同时抬高残差方差，出现"越有异常越判定无季节性"的反向效果。

**趋势窗为什么取 2 个周期**：半窗等于 1 个周期时，窗内不足一个完整周期，线性拟合会被周期波动带偏，把季节信号误吸进趋势项（经典 STL 同样要求趋势窗 ≥ 1.5 周期）。

## 五、集成投票与样本量约束

### 投票规则

- `auto` 默认集成 `mad + iqr`，样本量 ≥ 14 时追加 `moving`
- 多数票：`minVotes = max(2, ⌈方法数 / 2⌉)`（单方法时阈值取 1）
- 命中点数 = 得分绝对值最大的那个方法的得分；`methods` 字段列出该点命中的所有检测器
- **高相关凑票的下限**：`mad` 与 `moving` 在趋势序列上高度相关（同一残差结构），`iqr` 极值围栏在内挤残差分布上同样缩水（实际仅约 2.7σ）；仅由这类"相关证据"凑满 2 票的点，要求 |得分| ≥ `CORRELATED_VOTE_FLOOR`(4.5) 才报告，不足者计入 warnings。集成投票防的是单方法误报，不能被高相关的第二票绕过

### 样本量门槛

| 有效点数 | 可用能力 |
|---------|---------|
| < 8 | **不检测**（返回 `detectable: false`） |
| 8 – 13 | 仅稳健方法（MAD + IQR 投票），警示"未启用局部窗口方法" |
| ≥ 14 | 追加局部线性趋势方法（`moving`） |
| ≥ 3 × 周期 | 才允许时序分解（`MIN_POINTS_PER_SEASON = 3`） |

### 多重比较与批量扫描

单序列检测按上述门限执行。**多指标 / 多维度批量扫描**时，同时检验的假设数 N 增大，误报率随 N 上升（N=20 条序列、单条 α≈1%，族错误率接近 20%），需做校正：

- **Bonferroni**：单序列阈值收紧为 `α/N`，稳健 Z 阈值整体抬高（如 N=20 时 MAD 阈值 3.5 → 约 4.2）。最保守，适合指标数少
- **Benjamini–Hochberg FDR**：按 `p` 值升序，取最大的 k 满足 `p_(k) ≤ (k/N) × q`（q 常取 0.05），控制"被报告的异常中假阳性的期望比例"。指标多时优先

批量扫描需要脚本未覆盖的能力时，走 `python_analysis` 工具执行（序列数据经 `input` 传入）。**按运行时 venv 实际已装的库选型**（numpy / pandas / scipy / scikit-learn / statsmodels / matplotlib）：离群检测用 `sklearn.ensemble.IsolationForest`；趋势+季节分解与预测用 `statsmodels` 的 `STL` 或 `UnobservedComponents`（状态空间局部趋势/季节模型，替代 Prophet）；变点检测用 numpy 自实现 CUSUM 或 `statsmodels.stats.diagnostic.breaks_cusumolsresid`；多重比较校正在 `statsmodels.stats.multitest.multipletests`（Bonferroni / Benjamini–Hochberg FDR）。**镜像未预装 Prophet 与 `ruptures`（PELT）**：确需时可经 `PIP_COMMAND` 现场安装，但依赖外网可用性，不应作为默认路径。

## 六、严重度分级与类型分类

### 严重度（三者取高）

| 严重度 | 判据 |
|-------|------|
| `CRITICAL` | 超出 3×IQR 极值围栏 **或** 稳健得分 ≥ 6 **或** 相对偏离 ≥ 100% |
| `MAJOR` | 稳健得分 ≥ 4.5 **或** 相对偏离 ≥ 50% |
| `MINOR` | 其余命中点 |

### 类型

| 类型 | 判据 | 常见业务含义 |
|------|------|-------------|
| `SPIKE` | 单点或少量点向上偏离 | 促销、活动、异常流量 |
| `DIP` | 向下偏离 | 渠道中断、缺货、数据延迟 |
| `LEVEL_SHIFT` | 变点确认（双窗中位数比较）或连续 ≥ 3 点同向异常（片段） | 口径/策略/上游变更，业务影响更大 |
| `ZERO_VALUE` | 异常点值为 0 | 优先按数据链路问题排查 |

水平位移片段的严重度不低于 `MAJOR`（持续位移的影响大于单点脉冲）。变点确认成立的位移（含不足 3 点连续异常门槛的短位移）同样判为 `LEVEL_SHIFT`，期望值取位移前水平。

### 相对偏离幅度

```
deviationRatio = |实际值 − 期望值| / max(|期望值|, |序列中位数|)
```

分母取期望值与序列中位数的较大者，避免期望接近 0 时比值爆炸。

### 实际意义下限

`deviationRatio < minDeviationRatio`（默认 0.03）的点**不列为异常**，只在 `warnings` 中提示数量。理由：统计显著 ≠ 值得关注——当序列几乎无噪声时，1%~2% 的正常波动也会算出很高的稳健得分，若不设下限，报告会被无意义的小波动淹没。需要纳回时下调 `minDeviationRatio`。

## 七、参数速查

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `method` | `auto` | auto/ensemble/mad/zscore/iqr/moving/stl/ewma |
| `direction` | `both` | both/up/down |
| `threshold` | 3.5 | MAD 阈值（也作为 `madThreshold` 别名） |
| `madThreshold` | 3.5 | 稳健修正 Z 分数阈值 |
| `zscoreThreshold` | 3.0 | 经典 Z 分数阈值 |
| `iqrK` / `iqrExtremeK` | 1.5 / 3.0 | 箱线图围栏倍数 / 极值围栏倍数 |
| `window` | 7 | 局部线性趋势窗宽（点数） |
| `movingThreshold` | 3.5 | 局部趋势残差阈值 |
| `alpha` / `l` | 0.3 / 3.0 | EWMA 平滑系数 / 控制限倍数 |
| `period` | 自动推断 | 季节周期；显式传 1 表示无季节性 |
| `minDeviationRatio` | 0.03 | 实际意义下限（相对偏离） |
| `maxAnomalies` | 50 | 返回异常点上限，超出则截断并提示 |

**引擎内置常量（不可经 params 配置）**：`SHIFT_WINDOW`=7（位移确认单侧窗长）、`SHIFT_WINDOW_MISSING_TOLERANCE`=3（位移窗口允许的缺失槽位数，每窗最少 4 点）、`SHIFT_Z_THRESHOLD`=3.5（双窗水平比较门限）、`CORRELATED_VOTE_FLOOR`=4.5（高相关凑票的得分下限）、`WINSOR_BOUND_SIGMA`=4.0（缩尾校正界）、`DECOMPOSE_REFINE_ROUNDS`=2（趋势/季节交替估计轮数，STL 内循环）、`GRANULARITY_STEP_TOLERANCE`=0.25（实测采样间隔与声明粒度的允许偏差）。

## 八、输入数据质量前置检查

| 检查项 | 处理 |
|-------|------|
| 时间字段 | 缺省识别含 `time/date/日期/时间` 的列；解析后**按时间升序重排**（乱序会让趋势/季节方法全部失效） |
| 时间缺口 | 缺行/缺失日期按真实时间映射到均匀网格坐标，季节相位与日历对齐、缺口处不参与差分（按下标取相位会让相位整体前移，实测 10% 缺行下 F1 从 0.21 掉到 0.07、周末误报翻 6 倍）；缺口数量在 `warnings` 中提示 |
| 粒度不符 | 实测采样间隔与声明粒度偏差超过 25% 时提示（缺口计数以检测到的节奏为基准：缺行近半时日粒度数据会被当成隔天采样、缺口计数为 0，此提示避免用户误以为数据完整） |
| 缺失/非数值 | 跳过参与统计，`warnings` 中给出数量；缺失比例 > 30% 提示数据质量风险 |
| 常量序列 | 整段无波动 → `detectable: false`，提示按数据链路问题排查（而不是报告"无异常"） |
| 样本量 | 有效点 < 8 → `detectable: false` |
| 异常点占比 | 异常点超过 `maxAnomalies` 时截断，提示缩小窗口或按维度拆分检测 |

## 九、方法选择决策树

```
序列是否有明显周期（星期/月度效应）？
├─ 有 → 用 auto（内部会自动分解并对残差检测）
│         └─ 周期明确时显式传 period，避免推断偏差
└─ 无 → 序列是否存在趋势？
         ├─ 有趋势 → 用 auto（含 moving 局部线性趋势残差）
         └─ 无趋势、近似平稳 → auto 即可（mad + iqr 已足够）
                 ├─ 分布明显偏斜 / 样本很小（8~13 点）→ 显式用 iqr
                 ├─ 需要捕捉缓慢水平漂移 → 显式用 ewma
                 └─ 样本干净、近似正态且需要更高检出率 → 显式用 zscore
```

一切默认走 `auto`；只有在有明确理由时才显式指定单方法。
