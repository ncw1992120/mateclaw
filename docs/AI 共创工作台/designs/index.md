# AI 共创工作台设计资料

更新日期：2026-10-23。

当前产品面向简单报表：用户用自然语言直接生成可运行前端，在同一工作台边设计页面、边绑定真实数据、边查看和验证结果、边修改。独立 S01 建设蓝图阶段已取消；原 S02 页面设计与 S03 数据对接合并为可交替进行的能力，不再按阶段串行移交。

## 当前产品规格

**从 [AI 报表共创工作台—产品设计](./AI报表共创工作台-产品设计.md) 开始阅读。** 这是本期统一的需求与验收依据，包含：

- 自然语言生成前端、选择组件和局部修改。
- 设计与数据绑定同步推进，单个组件可独立接入真实查询。
- 使用示例数据的组件持续显示“示例数据”水印。
- 加载、无数据、查询失败、权限不足和前端渲染失败的组件内反馈。
- Agent 根据对应组件的错误继续修复，修改后重新查询、渲染和核对。
- 保存页面、查询绑定和版本；当前版本的验证状态随变更更新。
- 本期范围与验收场景。

```text
用户描述 → 生成可运行报表
                 ↕
       页面调整 ↔ 数据查询与绑定
                 ↕
          查看、验证、定位错误
                 ↕
             继续修改、保存
```
