# AI 报表共创工作台 · 可交互 HTML

入口：[index.html](./index.html)。单文件、无外部依赖，可直接用浏览器打开；本地保存受浏览器对文件页存储的支持影响，推荐通过本地 HTTP 服务体验。

```bash
python3 -m http.server 18763 --bind 127.0.0.1 --directory 'docs/AI 共创工作台/designs/AI报表共创工作台'
```

访问 `http://127.0.0.1:18763/`。建议桌面宽屏使用；窄屏点击顶部“对话”打开或收起助手。

## 体验共创过程

左侧固定六组提示词，点击后会发送完整需求、展示 Agent 分步处理过程和结果，并真实修改报表状态。也可把相同提示词输入对话框发送。

| 场景 | 页面变化 |
| --- | --- |
| 01 生成销售分析 | 生成销售精英分析及六个示例组件；可撤销 |
| 02 切换霓虹风格 | 切换紫色霓虹主题，保留布局和绑定 |
| 03 接入销售数据 | 销售收入和趋势绑定模拟服务，刷新数值并移除对应水印 |
| 04 聚焦华东业绩 | 切换到 2026 年 9 月华东区，图表与明细联动 |
| 05 演示查询失败 | 趋势图显示查询错误、重试、详情和 AI 修复入口 |
| 06 修复并验证 | 修正模拟返回配置并重新查询、渲染 |

生成场景会替换当前报表，可撤销恢复。其他场景可单独执行；没有目标组件时会说明原因。重复生成可回到青蓝科技主题和初始数据范围。

## 其他可操作内容

- 点击组件标题：修改标题、图表类型、颜色、宽度；复制、删除组件。
- 数据查询面板：指标、分组、字段映射；模拟正常、空结果、查询失败、超时、权限不足及渲染异常。
- 图表：悬停查看数据；部门排名可点击联动筛选。
- 表格：搜索、排序、分页、CSV 导出。
- 页面：新增组件、拖动标题排序、前后移动、编辑/预览、当前页面验证、执行详情。
- 保存：当前浏览器本地存储及最多八个版本；恢复后绑定组件需重新执行查询，防止沿用过期验证。
- 撤销/重做：桌面顶部按钮，或 `⌘/Ctrl+Z`、`⌘/Ctrl+Shift+Z`；保存可用 `⌘/Ctrl+S`。

## 演示边界

AI 应答是固定场景及本地规则模拟，接口通过本地延时和状态切换模拟。所有销售数据及同比均为假数据；示例组件有水印，绑定组件标记“接口模拟”。前端编辑、查询状态、筛选计算、图表绘制、错误隔离、文件导出和本地保存实际生效。

此页面用于讨论 MVP 的使用体验，未接入后端、模型、真实权限及真实指标，不代表产品设计中的所有验收项已实现。
