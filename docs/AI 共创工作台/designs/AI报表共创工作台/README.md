# AI 报表共创工作台 · HTML 动态演示

## 两个页面

- [index.html](./index.html)：工作台，包含动态对话、执行卡片、组件配置、场景目录、验证及版本管理。
- [report.html](./report.html)：白底销售经营日报，可独立打开，也作为工作台中的实时预览。包含指标卡、趋势、部门排名、饼图和可交互明细。

两页通过消息同步同一份当前报表状态。工作台每轮显示用户需求、Agent 分步执行、逐段回应与产物变化。所有内容都是 HTML 元素，图表、表格及配置可继续点击操作。

## 运行

在仓库根目录运行：

```bash
python3 -m http.server 18763 --bind 127.0.0.1 --directory 'docs/AI 共创工作台/designs/AI报表共创工作台'
```

工作台：`http://127.0.0.1:18763/`；独立日报：`http://127.0.0.1:18763/report.html`。

使用相邻 CSS/JS 文件，不需要构建或安装依赖。建议通过 HTTP 打开以保证两个页面共享本地草稿存储。推荐桌面宽屏；窄屏以对话在上、日报在下排列。

## 推荐体验

1. 点击“开始完整共创”：重新开始本次对话，逐个生成六个组件。右侧默认打开编辑模式。
2. 点击“下一轮”：依次演示绑定收入、查询期间调整展示、新增并绑定饼图、限定筛选范围、渲染错误、定向修复、草稿保存恢复、范围验证。
3. “自动继续”逐轮推进；可停止自动继续。涉及影响确认、口径澄清和人工验证时会等待操作。
4. 点击“全部 26 个场景”可独立体验任一需求场景。必要时会补齐基础组件；不会让缺少前置步骤导致演示无法继续。
5. 右侧“编辑 / 预览”切换可随时查看编辑画布或最终报表。编辑模式下点击组件可选中并打开属性面板；点击标题旁的铅笔图标可直接改标题，拖动组件左上角把手调整顺序，拖右下角缩放把手调整宽高。
6. 编辑工具栏的“− / + / 适配”只缩放画布视图。选中组件后输入“把这个组件改成紫色柱状图”等指令，Agent 只修改当前目标；点击“整张报表”可回到整页讨论。
7. 在属性面板可直接修改组件类型、主题色、单位，也可调整指标、维度、月份、部门及模拟查询结果，然后单独应用展示修改，或保存查询配置并立即执行。
8. 输入“整张报表切换为暮光紫主题”或“切换为蓝青科技风”，Agent 会改变日报全局强调色并保留白色画布、组件数据和绑定。
9. 错误组件可以重试、请 Agent 修复、查看脱敏详情；权限错误保留阻塞说明。

场景目录中的完整提示词也可复制进输入框发送。自由输入仅支持有限本地规则，未识别的输入会给出说明，不会虚构执行成功。

## 实际运行的交互

- 渐进生成、局部展示编辑、组件选择、删除前确认、查询绑定、请求加载和字段/渲染错误隔离。
- 选中组件后定向 AI 对话、组件属性直接编辑、数据查询参数配置与执行、整页主题切换；展示变更保留绑定，查询配置变更会重新查询。
- 编辑 / 预览模式、组件拖动排序和角点缩放、组件标题内联编辑、画布缩放；布局及视图模式写入当前浏览器草稿。
- 示例、接口模拟、混合输入模式；逐组件水印、空结果、零值、历史结果时间与范围。
- 月份和部门联动、限定筛选目标、旧请求丢弃、筛选候选失败阻止查询。
- 共享查询修改前确认；失败与修复同步作用于依赖组件；删除单个消费者不删除其他引用。
- 明细搜索、排序、分页；独立日报同样可以筛选与查看详情。
- 当前浏览器草稿与最多八个版本，恢复后查询结果标为待验证；撤销同时恢复页面和绑定。
- 范围验证根据当前查询、渲染、交互及人工确认共同判断。接口仍为本地模拟，不代表真实业务链路已验收。

## 实现边界

数据、接口、权限、指标目录和 AI 应答全部为本地模拟；没有连接真实后端或大模型。预设剧情驱动真实前端状态变更，用于产品演示和需求讨论。S04–S06 后续目标不纳入此原型。
