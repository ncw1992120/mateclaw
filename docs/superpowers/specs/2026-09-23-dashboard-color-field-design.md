# 仪表盘统一颜色字段设计

## 目标

统一洞察仪表盘编辑器里用户可编辑颜色的交互：使用一个颜色色块按钮和一个可编辑颜色参数；点击色块可选色并查看最近使用颜色；选色或手动输入有效参数后，色块与参数即时同步。最近使用记录只保存在当前浏览器，并按登录用户在本地隔离，不上传服务端、不跨浏览器或设备同步。

## 当前状态与范围

现有颜色入口分布在新属性面板、旧卡片属性面板、KPI 字段样式弹窗、标题图标样式弹窗和主题外观面板。实现应统一交互而不改变各配置的持久化 Schema、主题继承行为或颜色作用范围。

纳入现有可编辑颜色项：

- 组件背景色与边框色：`visualStyle.background.color`、`visualStyle.border.color`。
- KPI 指标强调色与字段文字颜色：`visual.accentColor`、`styles[field].color`。
- 组件标题图标自定义颜色：`titleIconStyle.color`。
- 仪表盘主题辅色：`overrides.accentAlt`。

保留每个字段周边已有的主题/自定义/透明模式及重置行为；颜色字段只负责编辑颜色值和提供最近使用推荐。主题预设卡片、预览中的图表色板、运行时 CSS 状态色并非独立颜色输入，不新增它们的编辑能力。`CardContainerPrototype.vue` 是原型入口，不作为生产配置入口迁移，除非实现检查确认它仍被正式路由使用。

## 交互设计

新增通用 `InsightColorField`，以 `modelValue`/`update:modelValue` 提供标准 v-model，并允许调用方提供可访问名称及用途推荐色。控件布局为颜色预览/选择按钮 + 颜色参数输入框。选择按钮打开取色器，取色器预定义颜色中优先展示最近使用颜色；现有用途推荐色继续保留并去重显示。

支持不透明十六进制颜色。输入合法后立即规范化为大写 `#RRGGBB`、更新模型和色块；无效的中间输入保留在输入框并给出校验提示，不覆盖上一个有效颜色，也不写入最近使用记录。取色器选择后立即更新模型并记录最近颜色；手动输入则在 Enter 或失焦时提交最近颜色，避免逐字符编辑产生噪声记录。颜色模式仍由父级面板控制。

最近颜色去重后按最新使用时间置前，最多保留 12 项。历史损坏、LocalStorage 不可用或超额时，控件编辑不应失败：忽略无法读取/写入的历史，当前颜色照常工作。

## 本地用户隔离与生命周期

前端使用 `useUserStore().userId` 作为浏览器内命名空间：`mateclaw:insight:recent-colors:v1:<userId>`。同一浏览器中同一用户跨仪表盘复用；不同用户互相隔离；工作区切换不改变记录。未恢复用户 ID 时不读取或持久化任何账户历史，只允许当前控件临时编辑。

登出不删除已保存的用户颜色历史，使该用户下次在同一浏览器登录后仍可使用；此数据不是凭据或敏感数据。切换账号时，内存中的最近颜色立即切换到新用户命名空间。浏览器跨标签页 `storage` 事件更新共享历史；同一标签页的颜色控件使用共享响应式状态立即更新。

## 数据流与模块边界

1. `InsightColorField` 读取共享最近颜色状态，向父组件发送规范化颜色值。
2. 颜色历史模块负责按 `userId` 加载、校验、去重、置前、裁剪和写入 LocalStorage，并处理同标签页/跨标签页更新。
3. 现有面板继续负责字段语义：如切换对应 `colorMode` 为 `custom`、移除主题 override 以恢复默认、调用现有变更保存链路。
4. `color-presets.ts` 作为用途推荐色来源继续复用；避免把推荐色与最近使用色写回仪表盘 Schema。

不新增后端 API、数据库迁移或仪表盘 Schema 字段。

## 错误处理和兼容性

- 仅接受 `#RGB` 与 `#RRGGBB` 用户输入并规范化为六位大写 HEX；不支持 alpha，透明背景继续由现有模式表达。
- 从 LocalStorage 读取的数据逐项校验并规范化；非法项被忽略，最多保留 12 项。
- LocalStorage 的 JSON 解析、安全限制或配额错误不得阻止编辑器选择/输入颜色。
- 原有主题模式、组件自定义色和历史 Dashboard Schema 不做迁移；空值、缺失字段及预设主题行为保持原状。
- Theme accentAlt 的“恢复预设默认色”能力在换成统一控件后仍可操作，不能把清除 override 误当成设置空颜色。

## 验收标准

- 所有纳入范围的正式颜色编辑入口均使用同一控件，选择器与参数框双向同步。
- 有效手输在 Enter/失焦后进入最近列表；无效值不会改变生效颜色或最近列表。
- 最近颜色按登录用户在同浏览器隔离，登出重登后保留；切换工作区保持；切换用户不串色。
- 最近列表跨标签页保持同步；手动清除/损坏 LocalStorage 不影响编辑器可用性。
- 保存并重新打开仪表盘后，已有自定义颜色和主题继承结果保持一致。
- 完成颜色历史工具单元测试、组件交互测试、相关面板回归测试、前端类型检查和构建；如使用当前已运行浏览器，补充真实浏览器验收。

## 实施分段

1. 实现并测试用户隔离的浏览器颜色历史状态模块。
2. 实现并测试 `InsightColorField`，含参数校验、同步、最近色预定义值及可访问标签。
3. 迁移新/旧属性面板、KPI 样式弹窗、标题图标弹窗和主题辅色入口，保留各处模式与重置语义。
4. 做定向测试、类型检查、构建及可行的浏览器验收；检查旧色板和原型入口是否存在正式调用方。
