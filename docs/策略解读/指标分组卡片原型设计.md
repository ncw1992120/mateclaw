# 洞察仪表盘：KPI 指标分组卡片原型设计

## 一、文档说明

### 1.1 设计目标

本原型定义现有 KPI 卡片的通用指标分组能力。用户可以在一个 KPI 卡片中配置多个指标，并**直接在画布中拖拽 KPI 卡片与指标的位置、拉伸手柄调整大小（自由布局）**；指标展示通过「指标配置」汇总弹窗维护。

本能力属于“洞察 → 仪表盘 → KPI 卡片”的功能增强，不新增“策略指标卡”“用户指标卡”等业务专用组件。不同业务场景都通过同一个 KPI 卡片完成配置。

### 1.2 适用范围

```text
洞察
└── 仪表盘
    └── KPI 卡片
        ├── 单指标展示
        ├── 多指标分组展示
        └── 多 Tab 指标集合切换
```

KPI 卡片继续复用现有能力：

- 数据源和数据集配置；
- 多数据集组合；
- 字段映射和展示列名；
- 筛选器绑定；
- 时间筛选；
- Python 数据预处理；
- 数据预览和最终结果预览。

本原型只补充指标定义、指标排序、指标集合和指标切换，不重新设计数据集配置流程。

核心数据流向（结果集优先）：先由现有数据配置能力产出「最终结果集」（数据 + 字段元数据），再由结果集字段逐列自动映射出指标；**指标数量由结果集字段决定，不支持手动新增 / 删除指标**（也不提供计算表达式与值来源配置）。用户只对已映射的指标做展示配置：展示列名、单位（手动填写）、辅助说明。指标是结果集的投影，而非从零手工组装。

### 1.3 支持的指标内容

一个 KPI 卡片中的每个指标支持配置：

| 配置内容 | 说明 |
| --- | --- |
| 展示列名 | 预览态和发布态展示给用户的名称，即用户看到的指标名（可编辑） |
| 指标值 | 由结果集字段映射得到的数值，**只读不可编辑**，仅可配置其字体样式 |
| 单位 | 用户手动填写的展示单位（如 个、次、%、元），留空则不显示，独立配样式 |
| 辅助说明 | 指标下方的补充解释（固定文本，可编辑） |
| 展示状态 | 显示或隐藏 |

## 二、整体交互流程

```text
选择或新增 KPI 卡片
        ↓
打开 KPI 卡片属性配置
        ↓
配置数据源、筛选器与 Python 预处理，生成「最终结果集」
        ↓
系统按结果集字段（数据 + 字段元数据）自动投影出默认指标
        ↓
开启“多指标模式”（默认已按结果集投影出全部指标）
        ↓
用户修改展示列名、单位（手动填写）、辅助说明等展示配置
        ↓
（编辑态画布已绑定结果集直接出真实值）在画布中直接拖拽 KPI 卡片与指标的位置，并拉伸 8 向手柄调整大小（自由布局）
        ↓
保存 KPI 卡片
```

### 2.1 入口

路径：

```text
洞察 → 仪表盘 → 选择 KPI 卡片 → 属性配置
```

现有 KPI 卡片属性面板中的入口保持不变：

```text
组件标题
多指标模式
多 Tab 模式
数据集配置
筛选器绑定
Python 预处理
指标配置
```


### 2.2 默认状态

首次创建 KPI 卡片并配置完数据源后：

- 系统基于「最终结果集」的字段元数据自动映射出默认指标（结果集每列对应一个指标）；
- 指标值默认绑定到对应结果集字段，指标名 / 展示列名默认取字段元数据带出的中文名，比如“新客数”；
- “多指标模式”默认开启以反映结果集的多列结构；单指标场景仅在结果集仅有一列时收敛为单指标展示；
- “多 Tab 模式”默认关闭；
- 未配置数据字段、结果集为空时显示配置占位，不显示虚假业务数据；
- 结果集查询返回 0 行、或某指标列值为空 / 0 时，卡片显示该指标的空态：指标名正常展示，数值区显示「—」或「0」并附极小号「暂无数据」提示，不展示虚假业务数据；
- 结果集字段变化（新增列、改名、删除列）时，指标集合随之增量同步：新增列自动加为新指标，删除列移除对应指标，保留用户已改的展示配置。
- 指标单位默认不填，由用户在单指标编辑中**手动填写**；数值本身按字段类型默认展示（计数 / 金额千分位、比率显示百分比），不需要用户配置。

关闭多指标模式时，不删除已有指标，仅把展示收敛为单指标。重新开启后恢复原有指标集合。

## 三、编辑器页面布局

### 3.1 KPI 卡片属性面板

```text
┌──────────────────────────────────────────────┐
│ 属性配置                                     │
├──────────────────────────────────────────────┤
│ 组件标题     [ KPI 指标卡                  ]  │
│ 多指标模式                              开   │
│ 多 Tab 模式                              关   │
├──────────────────────────────────────────────┤
│ 数据集配置                                   │
│ 筛选器绑定                                   │
│ Python 预处理                                │
├──────────────────────────────────────────────┤
│ 指标配置                                     │
└──────────────────────────────────────────────┘
```


规则：

1. 多指标模式关闭时，画布只展示第一个指标；
2. 数据集配置、筛选器绑定和 Python 预处理继续位于指标配置区域上方；
3. “指标配置”固定放在属性配置面板最底部；
4. 点击“指标配置”打开汇总表单弹窗，逐行维护各指标的展示列名、单位、辅助说明与显示状态（「指标值」为只读列，来自结果集不可编辑），并通过字段后的“:”入口配置该字段样式（大小 / 字体 / 加粗 / 颜色）；卡片内指标右上角的“:”可直接进入字段样式弹窗（默认「指标值」），弹窗顶部「配置字段」下拉可切换 展示名 / 指标值 / 单位 / 辅助说明；
5. 编辑态画布已绑定结果集并直接展示真实值；画布为自由布局，KPI 卡片与卡片内指标均可拖拽位置、拉伸 8 向手柄调整大小；
6. 指标配置区域和数据集配置区域共用右侧属性面板滚动容器。

### 3.2 画布中的 KPI 卡片

```text
┌──────────────────────────────────────────────┐
│ KPI 指标卡                         [⋮]        │
├──────────────────────────────────────────────┤
│ 关联计划数          12                        │
│                                              │
│ 关联策略数          38                        │
│                                              │
│ 下发策略数          24,680                    │
│                                              │
│ 触达策略数          19,420                    │
└──────────────────────────────────────────────┘
```

仪表盘画布为**自由布局**：

- KPI 卡片可在画布中**拖动位置**，并拉伸 8 向手柄**调整大小**；其它组件同理；
- 卡片内的指标同样**自由定位**：可拖到卡片内任意位置，并拉伸手柄调整大小；
- 指标不再走响应式网格，位置与尺寸以像素为准（本轮不做响应式重排）；
- 卡片与指标均有最小尺寸限制，拖动 / 缩放时自动约束在容器范围内。

## 四、自由布局（卡片与指标的位置 / 大小）

（卡片与指标的拖动、缩放集中在本节；指标展示配置见第五节。）

### 4.1 画布中的自由布局

仪表盘画布为自由布局，**KPI 卡片与卡片内指标都支持用鼠标拖动位置、拉伸手柄调整大小**：

- 拖动卡片标题栏可移动 KPI 卡片；拖动卡片 8 向手柄可缩放卡片；
- 卡片内的指标可拖到卡片内任意位置；拖动指标的 8 向手柄可缩放指标；
- 拖动 / 缩放时实时预览，选中项高亮并显示手柄，重叠时置顶；
- 有最小尺寸约束，且拖动 / 缩放时自动约束在容器范围内。

### 4.2 单个指标块

- 展示内容：展示列名、指标值、单位、辅助说明；其中**指标值（数值）与单位分列渲染**，单位紧跟在数值后、可独立配样式；
- **指标块在编辑态不显示边框与底色**，以纯文本块呈现，保持卡片内视觉干净（悬停 / 选中时以浅色底与描边反馈）；
- 四者的字号 / 字体 / 加粗 / 颜色可按指标单独配置（见 §5.2）；指标值只读，仅可配样式；展示名 / 单位 / 辅助说明的文本可在样式弹窗展示区直接编辑；
- 指标块**右上角带“:”快捷入口**，点击直接打开该指标的字段样式弹窗（默认「指标值」，见 §5.2.1）；
- 缩放手柄位于指标块边缘，非选中态隐藏，避免干扰。

拖动与缩放只改变展示位置和大小，不改变指标与结果集字段的映射关系。

## 五、指标属性配置

### 5.1 指标配置入口（汇总表单弹窗）

指标由「最终结果集」映射生成，**不可手动新增**。点击属性面板底部的【指标配置】，打开汇总表单弹窗：一行一个指标，维护展示列名、指标值、单位、辅助说明与显示状态。

```text
指标配置
┌───────────────────────────────────────────────────────────────────────────┐
│ 指标(来源)  展示列名 :  指标值 :  单位 :  辅助说明 :   显示   操作          │
│ ───────────────────────────────────────────────────────────────────────── │
│ sent_count  [下发策略数] :  24,680 : [条] : [较上周期] :  ●    [同步]        │
│ plan_count  [关联计划数] :      12 : [个] : [        ] :  ●    [同步]        │
└───────────────────────────────────────────────────────────────────────────┘
                                                        [取消]  [确定]
```

- 每行首列为结果集**来源字段名**（只读标识）；
- 展示列名、单位、辅助说明可直接在行内编辑，**即时反映到画布**；
- **指标值**为只读单元格，直接展示结果集映射得到的数值，**不可编辑**，其后仅提供“:”用于配置字体样式；
- 显示开关控制该指标是否在卡片中展示；
- 每个字段后的“:”按钮用于打开该字段的样式弹窗（见 §5.2），可配置字段为 展示名 / 指标值 / 单位 / 辅助说明；
- **行末「同步」按钮（样式一键套用）**：把该指标的**整套样式**（展示名 / 指标值 / 单位 / 辅助说明 的大小 / 字体 / 加粗 / 颜色）一次性同步到**全部指标**；只同步**样式**，不同步展示列名、单位、辅助说明的**文本内容**，也不改变各指标与结果集字段的映射；
- 卡片内指标右上角的“:”为快捷入口，直接打开该指标的字段样式弹窗（默认「指标值」，见 §5.2.1）。

### 5.2 字段样式（大小 / 字体 / 加粗 / 颜色）

点击汇总表单中某字段后的“:”，弹出该字段的样式弹窗，配置**大小、字体、加粗、颜色**（左配置名 / 右配置内容，左右结构）：

```text
┌──────────────────────────────┐
│ 字段样式                  ×  │
├──────────────────────────────┤
│ 配置字段       [ 指标值 ▼ ]   │
│  「展示区」= 真实内容(可编辑/联动)│
│ 大小(px)              [ 28 ] │
│ 字体               [系统默认 ▼]│
│ 加粗 ●———   颜色 ■ #1f2329  │
├──────────────────────────────┤
│              [取消] [确定]    │
└──────────────────────────────┘
```

- 弹窗顶部提供**「配置字段」下拉**（展示名 / 指标值 / 单位 / 辅助说明），可在弹窗内直接切换要配置的字段，无需返回汇总弹窗；切换后展示区与各控件即加载该字段的当前样式。从汇总弹窗字段后的“:”或卡片指标右上角“:”进入时，下拉默认定位到对应字段（卡片“:”默认「指标值」）；
- 可配置字段：**展示名**、**指标值**、**单位**、**辅助说明**，四者互相独立；
- **展示区可编辑并实时联动卡片**：展示名 / 单位 / 辅助说明 的**文本内容可直接在展示区编辑**，修改即时写回卡片对应指标（实时联动）；**「指标值」来自结果集，展示区为只读，不支持编辑修改**，只能配置其字体样式；
- 卡片的**指标值（数值）与单位分为两个独立元素**渲染，各自套用所配样式（如数值大号加粗、单位小号灰色）；
- **每个指标单独配置**，不存在整卡统一字体（已取消原“指标基础属性”整卡弹窗）；
- 布局为**左右结构**：左侧为配置名，右侧为配置内容或按钮；“加粗”与“颜色”排在**同一行**，避免留白过多；
- **实时联动卡片指标**：编辑任一样式项（大小 / 字体 / 加粗 / 颜色 / HEX）即**实时写回卡片上对应指标**，展示区与画布指标同步刷新，无需先点「确定」；点「确定」仅关闭弹窗，「取消」回滚到打开时的全部字段样式（含弹窗内切换过的字段）；
- **加粗**为独立开关项，默认指标值加粗、展示名/单位/辅助说明不加粗；
- **字体**提供常见选项，覆盖中英文字体：系统默认、苹方 / 思源黑体、微软雅黑、宋体、黑体、楷体、等宽、Arial、Helvetica、Verdana、Georgia、Times New Roman、Courier New、Roboto；
- **颜色**以小方块取色器呈现，并**输出颜色参数（HEX）**；HEX 文本**可直接编辑**（如 `#ff5500`），编辑后反向同步取色器并实时联动卡片，取色器选择同样回写 HEX；
- 本轮样式项为 **大小 / 字体 / 加粗 / 颜色**，不提供数值格式配置。

#### 5.2.1 画布中指标的快捷入口

卡片内的每个指标块**右上角带一个“:”按钮**（悬停或选中时显现）。点击后**直接打开该指标的字段样式弹窗，并默认定位到「指标值」字段**，无需先进入「指标配置」汇总弹窗；弹窗顶部「配置字段」下拉可再切换到 展示名 / 单位 / 辅助说明。汇总弹窗中对应字段后的“:”仍可进入同一弹窗。

### 5.3 展示列名

规则：

- 展示列名用于编辑态识别、画布和发布后的最终展示，是用户唯一需要维护的名称；
- 内部指标 ID 由系统根据结果集字段自动生成并隐藏，用户不手写；
- 展示列名为空时阻止保存；
- 修改展示列名不修改底层数据集字段名；
- 仅修改名称不会触发数据重新查询。

### 5.4 指标值直接来自结果集映射

指标值直接来自结果集字段，无需也无法在「指标配置」弹窗中配置：

- 指标与结果集字段一一对应，值即该字段在结果集中的值；
- 结果集字段名可作为来源标识展示在「指标配置」弹窗中，但不可编辑；
- 当该字段已由 Python 预处理形成时，同样来自结果集，不影响指标映射。

### 5.5 单位（手动填写）

```text
单位          [ 个                         ]
```

规则：

- 单位由用户**手动填写**，默认留空，不自动带出；
- 单位只影响展示，不改变数据值；留空时数值后不显示单位；
- 数值本身按字段类型默认展示（计数 / 金额千分位、比率显示百分比），不需要用户配置格式。

### 5.6 辅助说明

```text
辅助说明      [ 较上周期                     ]
```

辅助说明为指标下方的固定文本说明：

- 支持固定文本，例如“较上周期”“含历史归档”；
- 可留空，留空时指标下方不显示说明；
- 本轮不提供字段 / 参数插值，也不提供“插入字段 / 插入参数”按钮（避免在指标配置弹窗中引入额外配置）。

## 十一、原型页面状态清单

画原型时至少提供以下页面或状态：

1. 单指标模式的 KPI 卡片属性面板；
2. 开启多指标模式后的画布（结果集映射生成的多个指标）；
3. 「指标配置」汇总表单弹窗；
4. 字段样式弹窗（大小 / 字体 / 加粗 / 颜色，预览与卡片真实值联动，颜色以 HEX 输出）；
5. 指标显示 / 隐藏态；
6. 画布中拖动卡片位置 / 缩放大小的选中态；
7. 画布中拖动指标位置 / 缩放指标的选中态；
8. 开启多 Tab 模式后的指标集合 Tab；
9. 指标空态 / 零值态（结果集 0 行或值为空）；
10. 真实数据填充后的 KPI 卡片（编辑态即出数）；
11. 保存成功反馈。

## 十二、验收标准

### 12.1 通用性

- 不新增任何业务专用 KPI 组件；
- 策略、用户、订单等不同业务都通过同一 KPI 卡片配置；
- 展示列名、单位和业务说明均为配置内容（内部指标 ID 由系统自动生成，不暴露给用户）；
- 指标模型可以被未来其他数字卡片或容器复用。

### 12.2 指标配置

- 指标由「最终结果集」字段逐列自动映射生成，数量由字段决定，不支持手动新增 / 删除指标；
- 每个指标固定对应一个结果集字段，「指标值」在「指标配置」弹窗中**只读展示、不可编辑**；
- 可在「指标配置」弹窗中配置展示列名、单位（手动填写）、辅助说明与显示状态；
- 每个指标的 展示名 / 指标值 / 单位 / 辅助说明 可单独配置大小、字体、加粗、颜色（无整卡统一字体）；
- 支持把某个指标的**整套样式一键同步到全部指标**（汇总表单行末「同步」按钮）；只同步样式、不同步文本内容，也不改变字段映射；
- 编辑态指标块不显示边框与底色；每个指标块右上角“:”可直接打开其字段样式弹窗（默认「指标值」）；
- 字段样式弹窗的展示区与卡片真实值联动，展示名 / 单位 / 辅助说明 文本可在展示区直接编辑并实时联动卡片，指标值只读；颜色配置以小方块取色并输出 HEX 参数；
- 画布为自由布局，KPI 卡片与卡片内指标均可拖动位置、拉伸 8 向手柄调整大小；
- 支持“重置布局”恢复初始位置与大小；
- 单个指标块有最小尺寸限制，拖动 / 缩放不越出容器。


### 12.4 数据和预览

- 指标配置复用现有 KPI 数据集能力；
- 预览前遵循现有筛选条件要求；
- 预览可以查看指标值、字段来源、执行信息；
- 指标的展示配置（列名 / 单位 / 辅助说明 / 显示 / 样式）统一在「指标配置」弹窗中维护；
- 编辑态画布已绑定结果集并直接出数，不再提供独立的「组件预览」入口；
- 卡片与指标的拖动 / 缩放只改变展示位置和大小，不改变数据绑定；
- 多数据集和 Python 处理结果能够作为指标值来源；
- 预览失败不清空已有配置和上一次成功结果。

### 12.5 保存与自由布局

- 保存前拦截未完成指标和正式发布级绑定冲突；
- 保存后刷新页面，卡片与指标的位置、大小和样式保持一致；
- 拖动 / 缩放受最小尺寸约束，指标不会拖出卡片、卡片不会拖出画布；
- 支持“重置布局”恢复到默认排布。

## 十三、本轮设计边界

本轮只定义现有 KPI 卡片的指标分组增强，不新增以下能力：

- 不为某个业务场景创建专用 KPI 组件；
- 不在指标配置中复制数据源、数据集或 Python 编辑器；
- 不支持手动新增 / 删除指标、计算表达式和值来源配置（指标完全由结果集字段映射）；
- 不要求用户直接编辑 JSON 或手动填写内部 ID；
- 不为每个指标增加一套独立筛选器入口；
- 不把指标展示列名写回底层数据集字段名；
- 不在本轮设计新的数据库查询语言；
- 不规定具体前端拖拽库和表达式引擎实现；
- 本轮不再提供「组件预览」按钮（编辑态画布已实时出数），也不提供整卡统一的「指标基础属性」弹窗（样式按指标单独配置）。
