# 洞察仪表盘：主题外观原型设计

> 本文档基于 `docs/plans/2026-09-21-insight-dashboard-visual-theme-implementation-plan.md`（下称实施计划）的 §1 契约与 §1.3 配置页面要求，细化前端交互细节。本文档不改变实施计划中的 Schema 字段、颜色优先级与任务边界；若讨论中调整了契约，先回写实施计划再实施。

## 一、设计范围

本期只设计「主题外观」配置能力，覆盖三个交互面：

1. 编辑器顶栏「主题外观」入口与主题配置抽屉（预设 + 自定义）；
2. 指标样式弹窗（MetricStyleDialog）重设计——简化为「例外管理器」，并新增「图标与强调色」；
3. 画布 / 组合卡片 / 正式预览对主题的即时响应与保存链路；
4. 卡片级「密度档」与各组件（数据表格、筛选器、图表等）的主题消费规则（§5.2）。

本期非目标：全站主题（light/warm/eye-care/dark）编辑器、图表类型扩展、远程图标市场、AI 自动配色。全站主题只作为画布配色的叠加环境参与验证（QA-08）。

设计原则：

- **改了立刻能看见，看不见的不许改**：所有配置变更在画布即时预览；未点「保存仪表盘」前不写后端、不发数据查询。
- **显式优先级可视化**：旧固定 HEX 在 UI 中明确标注「自定义」，切换主题时它不动，用户不产生「改了没生效」的困惑。
- **不污染**：仪表盘主题只作用于编辑器画布与正式预览画布；侧栏、弹窗外壳、其他页面保持全站主题。

## 二、整体交互流程

```text
进入仪表盘编辑器 → 点顶栏「主题外观」→ 抽屉打开（画布保持可预览）
→ 选预设（立即变色）→ [可选] 展开自定义，改颜色/色板/圆角/阴影
→ [可选] 打开某指标「样式」，配图标与强调色
→ 点「保存仪表盘」（沿用既有保存按钮，抽屉不另设保存）
→ 正式预览 / 刷新 / 复制后视觉一致
```

## 三、入口与主题外观抽屉

### 3.1 布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ ‹ 返回   仪表盘编辑器   [策略解读 ▾]     撤销 重做   ◎ 主题外观    [保存]      │
├───────────────────────────────────────────────┬──────────────────────────────┤
│                                               │ 主题外观                 [✕] │
│              画布（保持可交互预览）             │                              │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐          │  预设主题                     │
│  │ KPI     │ │ KPI     │ │ 折线图   │          │  ┌────┐  ┌────┐  ┌────┐     │
│  └─────────┘ └─────────┘ └─────────┘          │  │blue│  │靛蓝│  │青绿│     │
│  ┌──────────────────────────────┐             │  └────┘  └────┘  └────┘     │
│  │ 组合卡片                      │             │  ┌────┐  ┌─────────┐        │
│  └──────────────────────────────┘             │  │琥珀│  │深色数据  │        │
│                                               │  └────┘  └─────────┘        │
│                                               │  ▸ 自定义                    │
│                                               │  [恢复预设]                  │
└───────────────────────────────────────────────┴──────────────────────────────┘
```

交互规则：

- 抽屉从右侧滑出，宽度 360px（允许范围 320～420px）；画布不重排、不缩放，主题变化通过 CSS 变量即时生效。
- 顶栏入口按钮带当前主题状态提示：非默认主题时按钮旁显示当前预设名的色点（如 `● 青绿`）；存在未保存草稿时追加星号（`● 青绿 *`），保存成功后消失；默认 `blue` 且无草稿时不额外显示。让用户不打开抽屉也知道当前主题与草稿状态。
- 抽屉打开期间画布可正常拖拽、缩放、选中组件——主题预览不打断既有编辑操作。
- 抽屉跟随编辑器会话而非单个页面：切换页面 Tab / 选中其他组件时抽屉保持打开，预览持续生效。
- 关闭抽屉（✕ / Esc / 点画布外）不丢草稿：未保存的主题配置在本次编辑会话内保留，与编辑器其他配置的草稿语义一致；刷新页面后回到最近一次已保存状态。
- 抽屉内长内容滚动，`保存` 按钮仍在顶栏可达（抽屉不遮住顶栏）。

### 3.2 预设主题缩略卡

```text
┌────────────────┐
│ ▆▆▆▆▆▆▆▆▆▆▆▆▆ │ ← 页面背景色的迷你画布
│ ┌──┐  ┌──┐     │
│ │▉ │  │▉ │     │ ← 两张迷你卡片：卡片背景 + 主色数字 + 图标占位
│ └──┘  └──┘     │
│ ╱╱╱╱╱╱╱        │ ← 迷你折线，用该预设图表色板前 3 色
│ ◉ 云枢蓝    ✓  │ ← 中文名称 + 选中标记（✓ 与描边双确认，不单靠颜色）
└────────────────┘
```

- 五张缩略卡横向网格排列（3 + 2），名称统一中文：云枢蓝（blue，默认）、靛蓝（indigo）、青绿（teal）、琥珀（amber）、深色数据（dark-data）。
- 缩略卡是纯静态预渲染 SVG/CSS，不跑真实组件；选中态 = 描边 + ✓ + 背景微亮。
- 点击缩略卡立即更新画布（改的是草稿 `theme`，未入库）；再次点击当前已选预设无副作用。
- 深色数据（dark-data）可在全站任意主题下选用：全站 light 下画布呈「深色岛」是**预期效果**，不做组合限制；缩略卡如实以深色画布呈现，用户选择前即可预知效果。
- 缩略卡上不展示「对比度校验失败」之类的错误——预设自身保证可读，错误只出现在自定义层。

### 3.3 自定义层

```text
├ 自定义 ────────────────────────────── [恢复预设] ┤
│                                                  │
│ 基础色                                            │
│   主色        [#1E40AF ▾]                         │
│   页面背景    [#F5F7FA ▾]                         │
│   卡片背景    [#FFFFFF ▾]                         │
│   边框        [#E4E7ED ▾]                         │
│   正文文字    [#1F2329 ▾]                         │
│   次要文字    [#6B7280 ▾]                         │
│                                                  │
│ 语义色（涨跌方向不在此处，由组件语义色控制）          │
│   正向 [#16A34A]   负向 [#DC2626]                  │
│   警告 [#D97706]   信息 [#2563EB]                  │
│                                                  │
│ 图表色板（顺序即数据系列顺序）                       │
│   1 [#1E40AF]  2 [#7C3AED]  3 [#0891B2]          │
│   4 [#16A34A]  5 [#EA580C]                        │
│                                                  │
│ 形状                                              │
│   圆角   ( 小 | 中●| 大 )    阴影   ( 无 | 柔和●| 明显 ) │
│                                                  │
│ ⚠ 正文文字与卡片背景对比度 3.9:1，低于 4.5:1 要求；   │
│   保存前请调高文字亮度或加深卡片背景。                │
└──────────────────────────────────────────────────┘
```

交互规则：

- 自定义默认折叠；展开后**未覆盖的字段直接显示当前预设的解析值，后缀灰字「预设」**（如 `#1E40AF 预设`），用户看到的是真实生效色，无需换算；点开取色器修改后才变为「已覆盖」，显示用户值并可一键还原为预设值。
- 每个颜色项：点击色块打开取色器（色板来源统一 `color-presets.ts` Token）+ HEX 输入框；HEX 输入支持 3/6 位，非法输入就地红框 + 文案「HEX 格式不正确，如 #1E40AF」。
- **对比度校验组合**：第一版只校验三组文字组合——正文文字 × 页面背景、正文文字 × 卡片背景、次要文字 × 卡片背景（正文/次要 ≥ 4.5:1）；主色不参与文字校验，仅在作为图标/强调色渲染时按 3:1 图形标准由指标预览行就地校验。任一文字组不合格：该色块描红 + 底部错误条（写明具体比值和要求），**顶栏「保存」置灰**并悬浮提示原因；修复后自动解除。
- 语义色（正向/负向/警告/信息）**开放自定义**，独立分组呈现；涨/跌方向色（`--db-up`/`--db-down`）**始终锁定**不提供任何配置入口——这是实施计划的红线。分组旁固定一行说明「涨/跌方向色由组件语义控制，不随主题变化」。
- 图表色板按序号列表展示，色序即 ECharts 系列顺序；**不支持拖拽排序**（已确认：排序涉及已存图表的重着色语义，留待后续单独讨论）。
- 「恢复预设」：只清空 `theme.overrides`（含自定义色/色板/圆角/阴影），回到当前预设的纯净状态；**不影响**任何指标级 `visual` 单项覆盖（图标、强调色、旧 HEX）。点击需二次确认（ElMessageBox，与删除子组件同款），文案明确「将清除仪表盘级自定义颜色，指标上的单项配色不受影响」。

## 四、指标级配置：图标与强调色

### 4.1 MetricStyleDialog 重设计（2026-09-21 简化定稿）

> 现有版本复杂度来源：字段下拉切换、颜色双入口（取色器 + 独立 HEX 输入行）、14 项字体下拉、右侧 300px 展示区与画布实时预览冗余。本次随主题化重构为「例外管理器」：仪表盘主题 + 指标色板 + 默认图标已解决 80% 的视觉层次，指标级只负责配置例外。

```text
┌─ 指标样式 · 当前合同额 ────────────── ✕ ┐
│                                          │
│ ── 图标与强调色 ──                        │
│ 图标    [ 📈 趋势 ▾ ]  [清除]             │
│ 强调色   ( 跟随主题 | ● 自定义 ) [#B45309]│
│ 预览    [📈] 1,284.5 万   画布同步预览    │
│                                          │
│ ── 四字段样式（平铺，不再下拉切换）──      │
│ 字段     字号        粗细    颜色          │
│ 展示名   ▬▬●▬▬ 14   ☑     [▨] 主题        │
│ 指标值   ▬▬▬●▬ 28   ☑     [#B45309] 自定义│
│ 单位     ▬●▬▬▬ 12   ☐     [▨] 主题        │
│ 辅助说明 ▬●▬▬▬ 12   ☐     [#1F2329] 旧配色│
│                                          │
│ [重置该指标]                    [关闭]    │
└──────────────────────────────────────────┘
```

交互规则：

- **弹窗 420px 单栏**：画布实时同步即完整预览；弹窗内只保留强调色单行内联预览（图标 + 数值），承担 3:1 对比度就地校验。
- **删除字段下拉**：四字段（展示名/指标值/单位/辅助说明）平铺为表格，每行 = 字段名 | 字号滑杆（10–40px；未显式改动时跟随卡片密度档，改动即成为该指标显式例外，双击重置 = 清除例外回到密度档）| 粗细开关 | 颜色色块。
- **删除「颜色 HEX」独立输入行**：色块即唯一入口；「跟随主题」状态点击色块 = 直接切到自定义并打开取色器（内含 HEX 输入与项目色板），取色器内「还原预设」回到跟随主题。
- **删除字体下拉（14 项）**：字体上移为仪表盘级一致性属性（后续可在主题面板提供），指标级不再暴露；旧 Schema `styles.*.family` 保留读取与 round-trip，UI 不展示、不改写。
- **颜色默认「跟随主题」**（斜纹占位色块 + 「主题」灰字）；自定义后显示实际色值；旧固定 HEX（无 `colorMode`）自动标「旧配色 · 切主题不变」，用户不主动改则原值原样保留，切换主题它不动；新建指标默认「跟随主题」，无固定 HEX。
- **强调色的作用域仅限图标着色与数值强调**，不改文字四字段的色（文字色由各行自己的颜色列决定）。
- 图标键跟随 `fieldKey` 绑定，拖拽排序 / 切 Tab / 复制组件不串图标；默认图标按指标顺序循环使用注册表前 N 个（已确认：不做 `fieldKey` 散列，顺序循环可预期、可解释）。
- **即时生效**：所有修改直接写编辑器草稿并同步画布，无「确定/取消」——与现版「关闭即生效」的保存语义一致，符合「改了立刻能看见」原则。
- **「重置该指标」**：四字段回跟随主题、图标清除、强调色回跟随、字号回默认；不设二次确认（可低成本重做），toast 提示已重置。
- 图标选择器交互不变（见 4.2）；强调色与卡片背景对比 <3:1 时预览行就地标红提示，不阻断编辑。

## 五、颜色与图标优先级（交互层面的含义）

```text
页面/卡片背景   旧 Schema：全站 --db-* Token
              新 Schema：仪表盘预设 + 自定义覆盖
图表颜色       图表显式 option.color > 仪表盘图表色板 > ECharts 默认
指标强调色     指标自定义 > 组件自定义 > 图表色板[稳定序号] > 主色
指标文字色     styles.*.colorMode=custom 的 HEX（含旧 HEX）> 主题语义 Token
涨跌/状态色    --db-up/--db-down 与 --db-positive/--db-danger 独立，永不改写
图标           指标 iconKey > 注册表按指标顺序的默认图标 > 无图标
```

对用户的呈现原则：优先级冲突时 UI 要「显示谁在生效」。弹窗中显示「自定义（来自旧配色，切主题不变）」或在图标/强调色行旁提示「由仪表盘色板第 N 色决定」。

### 5.1 主题作用域映射（哪些跟着变、哪些不变）

| 范围 | 元素 | 取值 |
| --- | --- | --- |
| 跟随主题（画布内即时生效） | KPI 图标色、数值强调色 | 强调色链：指标自定义 > 色板[稳定序号] > 主色 |
| | 四字段文字色 | 跟随主题时取 `text`/`textMuted`；自定义/旧 HEX 恒不变 |
| | 折线图系列与圆点、图例色块 | `chartPalette` 按系列顺序 |
| | 坐标轴文字、网格线 | `textMuted` / `border` |
| | 页签选中色、分节标题竖条 | `primary` |
| | 画布背景、卡片背景、边框、圆角、阴影 | `background`/`cardBackground`/`border` + 形状设置 |
| | AI 分析按钮 | `text` 与 `card` 反色 |
| | 筛选器等画布内控件外观 | `card`/`border`/`textMuted` |
| 不跟随（编辑器外壳） | 顶栏与保存/预览按钮、左右侧栏、主题抽屉、指标样式弹窗、取色器 | 保持全站主题——「不污染」原则；深色数据预设下画布为深色岛，外壳不变 |
| 永远锁定 | 涨跌方向色 ▲/▼ | `--db-up`/`--db-down`，无任何配置入口（Q5） |
| | 顶栏「主题外观」旁色点 | 仅指示当前预设 `primary`，不参与画布着色 |

### 5.2 组件消费映射与「大量指标」策略

**原则：组件不自带主题配置面板，只声明消费哪些 Token**；全仓唯一例外规则 = 「组件显式配置 > 仪表盘主题」。

| 组件 | 主题消费方式 |
| --- | --- |
| 卡片（KPI 分组卡） | 背景/边框/文字随主题；指标强调色 = 色板[稳定序号]、图标 = 按序循环，仅例外单独配 |
| 组合卡片 | 子组件继承父画布主题；容器显式背景仍按现有优先级覆盖 |
| 全部 ECharts 图表 | `withDashboardChartTheme` 注入色板与轴/图例色；显式 `option.color` 优先 |
| 数据表格 | 表头底色 = 卡片底混入 primary 6%、正文 `text`、表头文字 `textMuted`、边框 `border`、斑马纹混入 `background`、hover 混入 primary 8% |
| 筛选器 / 时间筛选 | 控件边框 `border`、文字 `text`/`textMuted`；**Teleport 到 body 的下拉面板必须显式传入变量**，不依赖 DOM 祖先继承（§1.3 既有约束） |
| AI 分析 | `primary`/`info` 点缀，主按钮按 text/card 反色 |

**单卡大量指标（10～20 个）的解法——不逐个配置：**

1. **配色与图标：自动循环**。按 `fieldKey` 稳定序号循环图表色板与图标库，20 个指标天然获得可区分的层次，零配置；用户只对需要突出的个别指标覆盖强调色/图标。
2. **背景：不逐指标设置**。指标统一继承卡片背景；卡片容器的显式背景配置仍优先（既有规则）。
3. **字号：卡片级「密度档」**（已确认纳入本期，Q12；需回写实施计划为组件级 `density` 字段）。卡片提供 紧凑/标准/大号 三档（compact/standard/large，默认 standard），一次性映射 指标名/数值/图标 三组字号；优先级 = 指标显式 `size`（例外保留）> 卡片密度档 > 主题基准。控件位于卡片头部（仅编辑态可见），值随组件 config 持久化、随复制/AI 修改 round-trip；「恢复预设」只清仪表盘主题覆盖，**不影响**密度档。避免 20 个指标 × 4 字段的字号地狱。
4. 深色预设下以上规则全部同样生效；涨跌/状态色依旧锁定。

## 六、保存与草稿

| 动作 | 行为 |
| --- | --- |
| 选预设 / 改自定义 | 只改编辑器草稿 `schema.theme`，画布即时预览；不触发后端请求、不触发数据查询 |
| 关闭抽屉 | 草稿保留在编辑会话内存中；顶栏「主题外观」按钮的色点同步显示未保存状态（如 `● 青绿 *`） |
| 点「保存仪表盘」 | 走既有 `handleSave()`，主题随 `schemaJson` 入库；保存成功后星号消失 |
| 刷新页面 | 草稿丢弃，回到最近已保存主题（与编辑器其他配置草稿一致，不做 localStorage 持久化） |
| 保存失败 / 403 / 断网 | 错误就地展示在顶栏保存按钮附近；抽屉草稿不丢；正式预览仍显示上次已保存主题 |
| 复制 / AI 修改 | 主题与指标视觉字段随 Schema round-trip 保留（Task 3 契约，交互层无感知） |

## 七、状态矩阵

| 区域 | 必须覆盖的状态 |
| --- | --- |
| 主题外观入口 | 默认（blue）/ 已配置预设 / 有未保存草稿（星号）/ 保存中 / 保存失败 |
| 预设缩略卡 | 默认选中 / hover / 键盘聚焦 / 当前选中 / 加载中（主题解析失败时全部置灰 + 兼容提示） |
| 自定义取色器 | 跟随预设（占位）/ 已覆盖 / HEX 非法 / 对比度不足 / 校验通过 |
| 图表色板 | 跟随预设 / 已覆盖 N 项 / 非法色项单独标红 |
| 恢复预设 | 可用（有覆盖时）/ 置灰（无覆盖）/ 确认弹窗 / 确认后 |
| 指标图标 | 默认图标（按序）/ 用户选择 / 已清除 / 未知图标键（回退默认 + 提示） |
| 指标颜色 | 跟随主题 / 自定义新值 / 旧 HEX（自动标「自定义」）/ 对比度不足禁保存 |
| 正式预览 | 已保存主题渲染 / 旧 Schema 无主题（沿用全站 Token）/ 未知 presetId（安全回退 + 兼容提示） |

## 八、键盘与无障碍

- 顶栏入口、抽屉内所有控件、缩略卡、取色器、图标网格全部键盘可达；焦点环可见，不依赖 hover。
- 缩略卡是 radio group 语义（`role="radiogroup"`），方向键切换预设并即时预览。
- 对比度错误、HEX 非法通过 `aria-describedby` 关联到输入框，读屏可感知；不只靠红框。
- 图标均有 `aria-hidden="true"` + 相邻文字名称或 `aria-label`；状态与涨跌保留图标/文字线索，不单靠颜色。
- 预设切换的画布过渡 ≤ 200ms，遵守 `prefers-reduced-motion`（reduce 时直接切换，无过渡动画）；ECharts 主题重绘不做动画插值，一次性 `setOption` 完成换色。

## 九、响应式

```text
≥ 1280px：抽屉 360px 靠右，画布不重排
768～1279px：抽屉改为覆盖式（遮罩 + 抽屉），关闭恢复画布
< 768px：抽屉全屏，预设缩略卡改 2 列，色板换行；保存按钮固定底栏
```

- 各断点下抽屉内容可滚动、无横向溢出；375px 宽度下 20 指标长名称场景以 QA-18 为准验证。
- 全屏抽屉下 Esc 关闭 + 焦点回落到顶栏入口。
