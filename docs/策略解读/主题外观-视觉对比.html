已落地：分区键从「组件类型 5 组」收敛为「3 个语义区」——数据区（KPI/图表/表格）用主色 #1E40AF，洞察区（AI）用辅色 #0F766E，控制区（筛选器/时间筛选）不下发 accent 走中性。卡内多指标不再色相轮转，一律同色，只靠图标轮转区分。整页强调色 = 2 个，第 3 个留给用户在指标样式里显式指定。

已按方案落地：src/utils/dashboard-theme.ts 新增 componentThemeZone()（data / insight / control 三区）与预设字段 accentAlt； componentThemeStyle() 不再按组件类型取 metricPalette[0..4]，控制区直接返回空（走中性 --db-*）； resolveMetricVisual() 卡内多指标默认同色；同时补上未定义的 --db-accent-strong（原回退硬编码 #4f46e5，不吃主题）并删除零消费的 --db-card-group-N-bg。

仍未采纳「同列相同组件用不同色系」：画布是 GridLayout（x/y/w/h），「列」由 x 推导而非数据字段，拖拽换列就会换色，颜色与内容身份脱钩；且同列若放 KPI+图表+表格+筛选，按列分色立刻破 3 色预算。

下一步可选：若还要更强的视觉入口，可在数据区内部再加一层层级（主指标用 hierarchy=strong 或用户 custom 的第 3 色），而不是再加一个色相。
