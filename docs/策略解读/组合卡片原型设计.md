# 洞察仪表盘：组合卡片 / 卡片容器原型设计

## 一、文档说明

### 1.1 设计目标

在“洞察 → 仪表盘”中新增通用的“组合卡片 / 卡片容器”组件。用户不需要理解前端布局或事件编程，只需要通过拖拉拽和简单配置，就可以把多个已有组件组合成一个完整的业务区域。

本组件是通用能力，不针对某一个业务页面、某一种指标或某一种数据源设计。策略解读只是本组件的一个使用示例。

### 1.2 允许组合的子组件

组合容器允许添加以下已有或后续新增的组件：

| 子组件类型 | 用途示例 | 是否允许嵌套 |
| --- | --- | --- |
| KPI 卡片 | 展示单个或多个核心数值 | 是 |
| 图表 | 柱状图、折线图、饼图等 | 是 |
| 图标 | 展示状态、趋势或业务含义 | 是 |
| 筛选项 | 让用户输入筛选条件 | 是 |
| 时间筛选 | 让用户选择时间范围 | 是 |
| AI 分析 | 展示数据解读、建议或异常说明 | 是 |
| 操作类组件 | 查询、刷新、导出、跳转等 | 是 |
| 其他容器 | 形成多层页面结构 | 是，但需要防止无限嵌套 |

### 1.3 核心原则

1. 容器负责布局、统一外观和作用域；子组件负责自己的数据展示和具体配置。
2. 用户看到的是“添加组件、拖动位置、调整大小、绑定范围”，不直接接触内部 JSON、事件总线或组件 ID。
3. 容器可以统一管理多个子组件，但不强制所有子组件使用同一个数据集。
4. 默认配置应尽量少；高级配置通过“更多设置”渐进展开。
5. 所有配置都应能在编辑态预览，并在保存前给出明确的校验结果。

## 二、整体交互流程

```text
进入仪表盘编辑器
        ↓
从组件面板拖入“组合卡片 / 卡片容器”
        ↓
调整容器位置和大小
        ↓
打开容器属性，设置标题、样式和布局
        ↓
向当前容器 / 当前页签添加子组件
        ↓
配置子组件的数据、字段、筛选器和展示方式
        ↓
配置容器级参数和事件作用域
        ↓
添加页签，并分别配置每个页签的子组件
        ↓
预览容器交互效果
        ↓
保存仪表盘
```

### 2.1 进入方式

路径：

```text
洞察 → 仪表盘 → 新增仪表盘 / 编辑仪表盘 → 组件面板
```

左侧组件面板中增加一个组件分组：

```text
布局组件
└── 组合卡片 / 卡片容器
```

用户可以采用两种方式添加：

- 将“组合卡片 / 卡片容器”拖到画布中的空白位置；
- 点击“添加到画布”，在画布中心生成一个默认大小的空容器。

### 2.2 默认生成状态

新容器生成后立即选中，并显示编辑边框、四角缩放点和容器工具栏。

```text
┌──────────────────────────────────────────────┐
│ 组合卡片                              ⋮  ×    │  ← 容器工具栏
├──────────────────────────────────────────────┤
│                                              │
│       拖入组件到这里，开始组合仪表盘内容       │
│                                              │
│       [添加组件]              [容器设置]       │
│                                              │
└──────────────────────────────────────────────┘
```

默认值：

| 配置项 | 默认值 |
| --- | --- |
| 标题 | 组合卡片 |
| 布局 | 网格布局 |
| 背景 | 白色 |
| 边框 | 显示 |
| 内边距 | 16px |
| 页签 | 1 个默认页签，名称为“页签 1” |
| 子组件 | 无 |

### 3.2 区域职责

| --- | --- |

## 四、容器画布交互

### 4.1 选中容器

容器被选中时：

- 显示蓝色选中边框；
- 四角显示缩放手柄；
- 边框上方显示容器工具栏；
- 容器内部子组件显示轻量拖拽提示；
- 右侧属性面板切换到“组合容器”。

容器未选中时，不显示缩放手柄和编辑工具栏，只保留正常展示效果。

### 4.2 调整容器自身大小

用户可以通过以下方式调整容器大小：

1. 拖动容器四角缩放点，调整宽度和高度；
2. 在右侧“尺寸与位置”中输入宽度、高度、横坐标和纵坐标；
3. 选择“适应内容”，让容器根据内部布局计算最小高度。

调整过程中显示尺寸提示，例如：

```text
宽 720px × 高 360px
```

约束：

- 容器不能缩小到遮挡子组件；
- 子组件超出容器时显示警告，不自动静默裁剪；
- 启用响应式布局时，宽高使用栅格占位而不是固定像素；
- 保存时记录容器的布局信息，刷新页面后保持位置和大小。

### 4.3 容器工具栏

```text
┌────────────────────────────────────────────┐
│ 组合卡片       [添加组件] [添加页签] [设置] │
└────────────────────────────────────────────┘
```

工具栏操作：

| 操作 | 行为 |
| --- | --- |
| 添加组件 | 打开子组件选择面板，并将组件添加到当前页签 |
| 添加页签 | 新增页签并自动切换到新页签 |
| 设置 | 打开容器属性面板 |
| 更多 | 复制容器、置于顶层、删除容器 |

删除容器前必须二次确认，并提示“删除容器后，内部组件配置也会一并删除”。

## 五、向容器添加子组件

### 5.1 添加组件面板

点击“添加组件”或从左侧拖拽组件时，打开组件选择面板：

```text
┌──────────────────────────────┐
│ 添加到：组合卡片 / 页签 1     │
├──────────────────────────────┤
│ 搜索组件                       │
│                              │
│ 数据展示                       │
│  [KPI 卡片]  [图表]            │
│                              │
│ 交互组件                       │
│  [筛选项]    [时间筛选]         │
│  [操作按钮]                     │
│                              │
│ 智能分析                       │
│  [AI 分析]                      │
│                              │
│ 布局组件                       │
│  [组合卡片 / 卡片容器]          │
└──────────────────────────────┘
```

面板顶部明确显示添加目标，避免用户误把组件添加到其他页签或画布根节点。

### 5.2 添加后的默认行为

子组件添加成功后：

- 放入当前页签的第一个可用网格位置；
- 自动选中该子组件；
- 右侧切换到子组件属性配置；
- 容器显示“已添加 1 个组件”的轻量反馈；
- 如果容器开启了统一作用域，子组件自动继承容器作用域。

### 5.3 子组件移动和缩放

容器内部支持：

- 拖动子组件标题区域调整位置；
- 拖动子组件边缘调整宽度和高度；
- 网格吸附和对齐辅助线；
- 多个子组件边缘对齐；
- 子组件复制、删除和移入其他页签。

右侧属性面板提供同等的尺寸和位置输入，拖拽和表单修改应保持同步。

## 六、容器属性配置

选中容器后，右侧属性面板按以下顺序展示：

```text
组合容器属性
├── 基础信息
├── 尺寸与位置
├── 内部布局
├── 外观样式
├── 页签配置
└── 参数与事件作用域
```

### 6.1 基础信息

```text
基础信息
容器标题      [策略执行情况                    ]
容器描述      [展示策略执行相关指标              ]
显示标题      [开关                           开]
```

规则：

- 容器标题默认显示在容器顶部；
- 关闭“显示标题”只隐藏标题，不清空已填写的标题内容；
- 描述为可选项，较长内容在预览态自动换行；
- 标题和描述支持在画布中实时预览。

### 6.2 尺寸与位置

```text
尺寸与位置
宽度          [ 720 ] px       高度       [ 360 ] px
横坐标        [  24 ] px       纵坐标     [ 180 ] px
□ 适应内容高度        □ 锁定宽高比
```

容器支持固定尺寸和响应式尺寸两种方式。默认使用响应式网格，只有需要精确排版时才展开像素输入。

### 6.3 内部布局

```text
内部布局
布局方式      (● 网格布局  ○ 自由布局  ○ 垂直流式)
列数          [ 12 ]
行间距        [ 12 ] px
列间距        [ 12 ] px
子组件对齐    [ 左对齐             ▼ ]
```

布局方式说明：

| 布局方式 | 适用场景 |
| --- | --- |
| 网格布局 | 默认方式，适合 KPI、图表和分析卡片的组合 |
| 自由布局 | 适合需要自由摆放图标、标签或操作按钮的场景 |
| 垂直流式 | 适合内容高度不固定、按顺序纵向排列的场景 |

首次版本默认开放网格布局和垂直流式；自由布局作为后续能力保留时，页面可以先显示为“即将支持”或暂不展示。

### 6.4 外观样式

```text
外观样式
背景          [ 白色                         ▼ ]
边框          [开] 颜色 [ #E5EAF2 ] 粗细 [ 1 ] px
圆角          [ 12 ] px
内边距        上 [16] 右 [16] 下 [16] 左 [16]
阴影          [ 无                           ▼ ]
标题对齐      [ 左对齐                       ▼ ]
```

样式只作用于当前容器及其内部留白，不覆盖子组件自身的业务样式。子组件仍可以在自身属性中配置图表颜色、指标字体等展示内容。

### 6.5 页签配置

页签配置区域用于管理当前容器的页签，不与仪表盘顶部的页面 Tab 混淆。

```text
页签配置                                      [+ 添加页签]
┌────────────────────────────────────────────┐
│ ⋮  指标概览                    [复制] [删除]  │
│ ⋮  执行明细                    [复制] [删除]  │
│ ⋮  贡献分析                    [复制] [删除]  │
└────────────────────────────────────────────┘
```

页签支持：

- 新增；
- 重命名；
- 拖动调整顺序；
- 复制当前页签及其全部子组件配置；
- 删除；
- 选择默认打开页签。

页签名称编辑使用行内输入框。删除当前页签时，必须先切换到其他页签；删除最后一个页签不允许执行。

## 七、页签与子组件配置

### 7.1 页签画布

```text
┌──────────────────────────────────────────────┐
│ 策略执行情况                                  │
│ [策略概括] [策略执行] [策略贡献] [+]            │
├──────────────────────────────────────────────┤
│                                              │
│  当前页签：策略概括                            │
│  ┌──────────────┐  ┌──────────────┐            │
│  │ 关联计划数   │  │ 关联策略数   │            │
│  │ 12           │  │ 38           │            │
│  └──────────────┘  └──────────────┘            │
│  ┌──────────────┐  ┌──────────────┐            │
│  │ 下发策略数   │  │ 触达策略数   │            │
│  │ 24,680       │  │ 19,420       │            │
│  └──────────────┘  └──────────────┘            │
└──────────────────────────────────────────────┘
```

规则：

1. 页签栏位于容器标题下方、子组件画布上方；
2. 页签切换只切换当前容器内部内容，不刷新整个仪表盘；
3. 每个页签拥有独立的子组件列表和布局；
4. 页签可以继承容器级参数和事件，也可以配置自己的默认值；
5. 当前页签为空时显示“当前页签暂无组件”和“添加组件”。

### 7.2 子组件的归属

每个子组件必须明确归属到一个容器和一个页签：

```text
仪表盘
└── 组合容器：策略执行情况
    ├── 页签：策略概括
    │   ├── KPI 卡片
    │   └── KPI 卡片
    ├── 页签：策略执行
    │   ├── 图表
    │   └── 数据表格
    └── 页签：策略贡献
        ├── KPI 卡片
        └── AI 分析
```

子组件从一个页签拖到另一个页签时，必须经过明确的放置反馈，并在释放后更新归属关系。

## 八、容器级参数和事件作用域

### 8.1 作用域层级

```text
仪表盘作用域
└── 页面作用域
    └── 组合容器作用域
        └── 页签作用域
            └── 子组件作用域
```

参数或事件默认遵循“就近生效、向下继承”：

- 容器级配置默认作用于容器内全部页签和子组件；
- 页签级配置只作用于当前页签；
- 子组件可以关闭某个继承项或配置自己的覆盖值；
- 未绑定作用域的参数不自动影响任何组件。

### 8.2 容器级参数配置

```text
参数与事件作用域
参数
┌────────────────────────────────────────────┐
│ 参数名       来源              作用范围     │
│ 时间范围     仪表盘时间筛选     ● 全部子组件 │
│ 渠道         当前页签筛选       ● 当前页签   │
└────────────────────────────────────────────┘
                         [+ 添加参数绑定]
```

参数绑定交互：

1. 点击“添加参数绑定”；
2. 选择参数来源：仪表盘筛选、页面筛选、容器内筛选或固定值；
3. 选择作用范围：全部页签、当前页签或指定子组件；
4. 选择是否允许子组件覆盖；
5. 保存后在画布中以轻量标签显示已绑定参数。

容器不默认创建数据源或数据集。子组件仍按自身类型配置数据集；容器级参数只负责把筛选值、时间值或其他交互值传递给子组件。

### 8.3 事件绑定配置

```text
事件
┌────────────────────────────────────────────┐
│ 触发组件       触发动作       目标范围       │
│ 时间筛选       刷新数据         当前容器     │
│ 操作按钮       切换页签         指定页签     │
│ KPI 卡片       下钻             仪表盘页面   │
└────────────────────────────────────────────┘
                         [+ 添加事件绑定]
```

可配置的通用事件：

- 值变化：筛选项、时间筛选改变值；
- 点击：KPI、图标、图表、操作按钮被点击；
- 页签切换：容器内部页签发生切换；
- 查询完成：数据加载成功后触发；
- 查询失败：数据加载失败后触发。

可配置的通用动作：

- 刷新当前容器；
- 刷新当前页签；
- 切换到指定页签；
- 把当前值传给指定筛选器；
- 打开详情页面；
- 导出当前容器数据。

### 8.4 作用范围可视化

用户打开容器级绑定配置时，页面同时展示简化关系图：

```text
[时间范围]
     │ 作用于
     ▼
[策略执行情况]
     ├── 策略概括
     ├── 策略执行
     └── 策略贡献
```

关系图只用于帮助用户理解和选择，不要求用户编辑连线或操作内部事件名称。

## 九、子组件与容器的配置边界

### 9.1 容器负责的配置

- 容器标题和描述；
- 容器宽高和位置；
- 内部布局和间距；
- 背景、边框、圆角和内边距；
- 页签的增删改排；
- 容器级参数绑定；
- 容器级事件绑定；
- 预览和保存状态。

### 9.2 子组件负责的配置

- 自身数据源和数据集；
- 多数据集组合及数据预处理；
- 指标、维度和字段配置；
- 自身筛选器绑定；
- 图表类型和展示列；
- KPI 展示格式；
- AI 分析内容和生成条件；
- 操作类组件的动作内容。

子组件的数据配置继续遵循《原型设计.md》中的数据集、筛选预览和 Python 预处理规则。组合容器不复制一套数据配置入口。

### 9.3 容器级绑定与子组件绑定的关系

```text
容器绑定：时间范围 → 全部子组件
子组件绑定：渠道 → 仅策略执行页签中的图表
子组件覆盖：策略贡献 KPI 不接收渠道参数
```

同一个参数存在多层绑定时，优先级为：

```text
子组件覆盖值 > 页签绑定 > 容器绑定 > 页面绑定 > 仪表盘绑定
```

冲突时在属性面板中显示来源和覆盖提示，不直接覆盖用户已有配置。

## 十、预览模式

### 10.1 编辑态和预览态

顶部工具栏提供“预览”按钮。预览时：

- 隐藏拖拽边框、缩放手柄和编辑工具栏；
- 保留真实标题、页签、筛选器、时间筛选和操作按钮；
- 允许切换页签和触发组件联动；
- 显示加载、空数据和错误状态；
- 支持返回编辑态继续修改。

```text
编辑态：[预览]
预览态：[返回编辑]                         [保存]
```

### 10.2 容器预览检查项

预览页中至少验证：

1. 容器标题、背景、边框和内边距正确；
2. 子组件位置和大小没有溢出；
3. 页签切换只更新当前容器内容；
4. 容器级时间或筛选参数能传给目标子组件；
5. 子组件自身的筛选和数据预览规则仍然生效；
6. 操作类组件的动作反馈清晰可见；
7. 加载、无数据、失败和重试状态可识别。

## 十一、空态、加载态和异常态

### 11.1 空容器

```text
当前页签暂无组件
拖入组件或点击下方按钮开始配置
[添加组件]
```

### 11.2 子组件加载

容器保留标题和页签，子组件区域显示骨架屏。容器内多个子组件分别加载，不因一个子组件较慢而阻塞其他子组件。

### 11.3 子组件失败

失败信息只显示在对应子组件内部：

```text
数据加载失败
请检查数据集配置或筛选条件
[重试] [查看配置]
```

除非容器级参数解析失败，否则不把一个子组件的失败扩散为整个容器失败。

### 11.4 作用域冲突

```text
当前参数同时绑定到容器和子组件，子组件配置将覆盖容器配置
[查看绑定关系]
```

冲突提示属于配置反馈，不阻塞用户继续编辑；用户保存前需要明确处理未解决的目标组件引用。

## 十二、保存与校验

### 12.1 保存前校验

保存仪表盘前校验：

| 校验项 | 处理方式 |
| --- | --- |
| 容器没有标题且开启显示标题 | 提示补充标题 |
| 页签名称为空或重复 | 阻止保存并定位到页签配置 |
| 子组件超出容器边界 | 提示并定位到画布 |
| 事件目标已删除 | 阻止保存并要求重新选择目标 |
| 子组件数据配置不完整 | 在对应子组件显示错误状态 |
| 容器存在空页签 | 允许保存，但显示非阻塞提醒 |
| 容器嵌套层级超过限制 | 阻止继续嵌套并给出原因 |

### 12.2 保存反馈

```text
正在保存仪表盘…
保存成功，已更新组合卡片“策略执行情况”
```

保存失败时保留当前编辑内容、页签和布局，不自动清空或回退用户修改。

## 十五、验收标准

### 15.1 添加和布局

- 可以从组件面板拖拽生成组合容器；
- 可以通过拖拽或属性面板调整容器大小和位置；
- 可以向容器添加 KPI、图表、图标、筛选项、时间筛选、AI 分析、操作类组件和其他容器；
- 子组件可以在容器内部拖动、缩放、对齐和删除；
- 子组件不会因为切换编辑对象而丢失配置。

### 15.2 页签

- 容器至少保留一个页签；
- 可以添加、重命名、排序、复制和删除页签；
- 每个页签可以配置不同的子组件；
- 切换页签时只切换当前容器内容；
- 可以设置默认打开页签。

### 15.3 参数和事件

- 可以把筛选项和时间筛选绑定到容器作用域；
- 可以选择全部页签、当前页签或指定子组件作为作用范围；
- 子组件可以继承、关闭或覆盖容器级参数；
- 可以配置刷新、切换页签、下钻、导出等通用动作；
- 事件目标被删除时可以被识别并要求修复。

### 15.4 预览和保存

- 预览态不显示编辑控件，但保留真实交互；
- 子组件可以独立显示加载和错误状态；
- 保存前能提示布局、页签、数据和事件配置问题；
- 保存失败时保留用户当前编辑内容；
- 刷新页面后容器的布局、页签和绑定关系保持一致。

## 十六、本轮设计边界

本轮只定义组合容器的通用交互和原型结构，不在原型中新增以下实现细节：

- 不要求用户直接编辑 JSON；
- 不要求用户手动填写组件 ID 或事件总线名称；
- 不在容器层复制子组件的数据源、数据集和 Python 配置；
- 不把容器级参数强制转换成某一种数据库查询语法；
- 不把策略解读中的具体指标名称固化到通用容器组件；
- 不规定具体前端框架、拖拽库或后端存储实现。

后续开发需要先基于本原型抽取通用的容器、页签、布局、参数绑定和事件绑定模型，再接入具体的 KPI、图表、筛选器、AI 分析和操作组件。
